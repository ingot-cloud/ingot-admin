# 租户组织成员选择

适用于租户端表单中选择人员，包括单个负责人/经办人、多名参与人、组织内角色接收成员。平台域使用平台成员选择；选择部门作为动态来源、用户组或资源对象不属于本规范。

## 固定交互

- 编辑态使用 `InSelectionField` 回显已选成员（头像标签，可带「部门主负责人」等 suffix），点击框体或编辑图标、Enter/Space 打开独立对话框。只读态用 `InSelectionTag` 展示资料，禁用态不打开，不用远程下拉直接添加人员。标签样式见 [selection-field.md](selection-field.md)。
- 单选单栏，多选左候选/右已选双栏。左栏提供搜索、组织面包屑以及子部门和成员；部门只提供展开导航，禁止勾选部门或隐式全选其成员。展开进入分支，面包屑返回。
- 根入口只展示显式绑定根部门或未绑定任何部门的候选；只绑定普通部门不再出现在根，显式根+普通部门双绑定均显示。进入部门展示直属候选，子部门逐级展开。未分配必须按本租户全部实际关系判断，不得把不可见关系当作未分配。搜索在当前场景候选范围内跨部门进行，清空恢复原浏览位置。搜索字段按真实后端契约和字段权限声明。
- 按租户成员ID去重，跨部门、搜索、分页保留已选；同一人员在不同部门的选中状态同步。全选仅当前分支/搜索已加载的可选人员，忽略部门。右栏支持单项移除和清空当前可操作选择。
- 对话框确定只回填父表单草稿，取消/关闭保持父值；业务表单保存时才提交。重新打开回显草稿。主负责人等业务元数据通过扩展提供，普通成员选择不默认附带这些规则。

## 数据及权限

- UI 统一不等于候选权限统一。接收各业务场景自己的候选 loader，保留当前租户、角色/委派来源、数据范围、字段规则和排除项；提交仍重验。不为复用组件额外授予 member:read 或 department:read。
- 部门导航沿其读取权限；无资格时保留原场景可选成员池，使用“可选成员”并说明没有可浏览部门，不请求完整管理树来补齐名称。浏览的部门ID与正在维护的目标部门ID分开。
- 部门和成员按服务端默认20条分页/按分支加载，不拉全员后本地过滤。候选与已绑定是两个数据源；已有大量关联独立分页回显，禁止循环 ids 回查父列表。
- 旧的失效/受限/未加载关系不能被当作新增候选，也不能因未出现在页面中而删除。新增关联接口优先提交增删差量；已有业务接口若接收完整草稿，须在完整旧ID基础上合成增删结果，不得用已加载首屏替换原集合。清空不授权删除不可处理关系。姓名和部门上下文只显示后端允许的投影，不从更宽接口补回。
- 当前候选栏/分支使用 InLoading，提供空态、失败重试和不可用提示。相同请求合并；关闭、切换身份/租户/权限/业务来源时失效旧结果，避免迟到响应污染新草稿。

## 接入与验证

公共组件位于 admin-common，通过 loader 和业务扩展复用，业务插件不互相依赖。租户入口使用组织成员录入框或带组织模式的公共候选组件，平台及非人员对象保持原入口。

验证至少覆盖：部门不可选择但可展开、面包屑、搜索清空、跨页/跨部门去重、取消不写、确认回填、只读/禁用、关联差量、权限切换和迟到响应；调用方验证其提交权限及版本冲突。复用业务已有权限校验，不把组件测试当作服务端授权验证。


## 视觉与负责人扩展

- 多选840px等宽双栏、内容420px；外层24px、栏内16px，正文14px/22px，行48px、头像/组织图标32px，窄屏收缩。主题色、浅色提示/标签、边框、文字及悬停使用框架Token，禁止写死参考产品蓝色。
- 搜索下方是“组织名 › 当前部门”面包屑，祖先可返回、末级仅文本。组织名称仅用授权返回值；部门不可勾选，圆底组织图标，展开为主题色文字按钮。全选文案为“全选”，语义限当前分支/搜索已加载的可选成员。
- 右栏空选择留白；有选择时“已选：N 名用户”与“清空”。候选、已选使用同一成员头像/姓名快照，姓名下显示实际可见任职部门；仅确实零任职且根可读时使用后端显式 implicitRoot 展示投影；这些信息随候选/关联页返回，点击选择不另查详情，不以正在浏览的部门冒充任职。
- 负责人扩展标题“请选择”；多位负责人提示“可选择多位部门负责人，必须有一个主负责人”。从空集合选第一位有效成员自动设主，主题浅底标签“部门主负责人”，切换按钮“设为部门主负责人”。用户移除主负责人时可将首位已知可用的剩余成员设主；既有受限/不可用主负责人不能因打开、翻页或状态变化而自动替换。以上只修改草稿，普通多选不附加负责人规则。
- 搜索placeholder与后端实际支持及字段检索资格一致，不照抄尚未支持的邮箱/手机号/ID检索。

## 专用浏览与复选框

- 租户人员选择使用 `/v1/tenant/member-picker/browse`：普通成员、部门负责人、直接/委派分配分别声明 MEMBER / DEPARTMENT_LEADER / ASSIGNMENT；目标部门和委派来源不可省略或被通用成员池替换。一次返回导航与成员，独立20条分页；绑定关系仍走原关联分页，少量ID回显沿原接口。
- 搜索跨本场景候选池，清空恢复当前分支。根不可读但有局部部门范围时初始展示可浏览部门片段，选中分支后再显示直属成员。虚拟根展示不写入任职、不改变其他列表、计数、权限或token。
- Checkbox尺寸和圆角用框架变量，勾号沿当前 Element Plus 的原生居中规则；半选使用50%定位与一次translateY，适配框架16px尺寸；禁止固定 left/top 后继续叠加居中 translate，浅深主题均检查全选、半选和禁用态。

## 外部快照与追加加载

- 右栏由外部表单草稿初始化；完整数组直接展示。业务关联可传initialBoundPage，包含连续已加载records、最后成功current、size和原始total；不重复查询已有首屏，只有未加载关系才调用外部loader。确认返回最新快照供父级复用，取消不改父草稿。快照和当前目标、身份、权限及业务版本绑定，失效后不可继续回显。
- 租户组织候选/部门按默认20条逐页追加，实际滚动到相应加载区段触发，并保留“加载更多”点击入口；部分已选同样追加，完整已选只滚动。平台原分页不变。总数已覆盖、页位置已到末页或返回空页时隐藏加载更多及其占位；不可用/移除项不能使分页循环。
- 加载区居中，轻量主题文字按钮，统一上下间距与最小点击区域；加载中禁重复，失败保留旧数据并重试原页。不要以每次滚动或新增选中触发全量循环取数。浅/深主题下用21+条真实组件数据检查实际滚动、按钮可见性及加载完消失。
