# 实体候选选择交互

适用于管理台中选择人员、用户组、角色版本、应用、操作、资源对象等服务端实体的表单字段。固定枚举、日期、时长和少量本地常量不套用此规范。先核对目标接口的权限边界和候选归属；对话框展示不能代替提交时的服务端重验。

## 录入框与弹窗

- 字段使用可聚焦的录入框或按钮打开独立对话框；框内显示名称摘要，不要求用户录入裸 ID。对话框内完成搜索、分页和选择，确认才更新表单，取消保持原值。禁用和只读时不打开。
- 单选使用单栏候选列表；多选使用左侧候选、右侧已选的双栏结构。已选项跨页、跨搜索条件保留，右侧可单项移除或清空；全选仅作用于当前页。搜索和分页不应悄悄改变已选集合。
- 层级候选（例如角色→已发布版本）保留层级：父节点用于展开，版本叶节点才可选择；根和子层分别服务端分页。单选使用单栏，版本多选时右侧展示已选版本；不默认选择最新版。
- 相同名称的实体必须带必要上下文，例如操作显示“应用 / 资源 / 操作”或已限定应用时显示“资源 / 操作”。标签仅用于辨识，提交仍使用稳定 ID。

## 数据与状态

- 普通实体候选按服务端搜索和分页，默认每页 20 条；禁止用大页码拼全量。已拥有完整集合的派生数据（例如所选角色的全部操作）可以在弹窗本地搜索分页，并说明集合来源。
- 编辑时按当前权限和上下文回显已选名称。少量已知 ID 可分批回显；列表规模的绑定关系应使用独立关联分页接口。不可用、失效或无权项不得从更宽权限的列表补回，也不能默默显示为可提交候选。
- 上级选择变化时清理失效的下级选择和旧预览；切换身份、权限或弹窗实例时忽略迟到响应。重复打开同一上下文可以复用请求结果，但不能把过期缓存当作新的授权结论。
- 搜索至少支持关键词清空和页码重置；提供加载、空态、失败重试及后端明确不支持的提示。搜索、分页和回显使用同一权限过滤；确认时仍以当前有效候选为准。
- 使用已有 `InDialog`、主题 Token、UnoCSS 间距与现有按钮样式；窄屏下保持列表和已选内容可滚动，页脚操作固定。参考 `BizIamAuthorizationRecipients`、`BizIamAuthorizationRolePicker` 及委派选择器的实际用法，不复制其中的业务权限逻辑。

## 请求与已选回显（统一约定）

- 候选页与已选集合是独立状态。首屏、搜索、翻页或折叠节点未返回已选项，不等于该项失效。已选草稿保留 ID、名称、固定版本和必要层级路径；对话框打开时传入该快照，确认返回完整新选择，取消不更新。
- 同一身份、同一授权依据和资源上下文，打开普通选择器通常只请求候选第一页；不得同时由 watcher、点击事件和子对话框重复发起相同请求。进行中的相同请求合并，迟到响应按实例与上下文版本丢弃。
- 对象候选第一页同时返回层级标记；直接将该响应作为树或列表的第一页。不另发探树请求，不在已缓存名称时每次打开强制调用 ids 回显。首次编辑缺少信息可回显；大量已绑定关系使用服务端关联分页，不循环 ids 冒充关联查询。
- 多选已选关系可按页加载右侧名称，但未加载的已选 ID 独立保留；清空或移除才改变选择。无权或失效项不允许从通用列表补回名称。角色与版本分别分页，只有新增确认的固定版本才读取完整操作元数据。
- `InLoading` 罩住当前候选栏、当前树分支或正在加载的已选关系，保持其余已选内容稳定。不要混用 `v-loading` 或文本“加载中”替代管理台统一加载组件。

## 权限展示与范围配置

- 角色详情、委派确认操作及范围预览统一使用 `--in-permission-panel-bg`，浅色默认 `#f8f9fa`，深色使用主题柔和背景；业务组件不得复制硬编码背景色。保持同一圆角、应用分组线和树缩进。
- 说明区与首个 label 至少保留标准表单间距；操作 label、范围输入、对象输入使用同一网格或对齐基准。使用主题 Token 和现有步骤抽屉组件。
- 批量应用范围或同资源复制对象必须明确目标；有不同的已有配置时先确认覆盖。跨资源禁止复用对象集合。范围默认值必须显式进入草稿；不能将缺少配置推断成全部权限。


## 平台角色字段权限

- 应用目录仅维护字段能力，具体 visibility/editable 在平台角色固定版本按资源配置一次，各操作继承；不新增成员/组覆盖入口。共享和租户流程按管理域保留。
- 平台角色创建为左侧五步抽屉（信息、权限、范围、字段、预览），编辑权限为后四步；字段默认值使用后端安全元数据，不由 UI 推断 FULL。
- 字段按应用/资源显示名称和编码，只有 FULL 且资源支持时可勾选编辑；配置集合已完整加载时本地搜索、每页20条、跨页保留并提供全局进度和错误定位。
- 权限资源变化清理失效字段，保留仍有效配置；字段/范围/信息变化必须使旧预览失效，忽略迟到预览。角色详情、分配、委派、升级和诊断仅展示固定版本摘要，不在分配时改字段。
- 使用 InLoading 与 --in-permission-panel-bg，平台固定版本必须有显式字段快照，未声明字段按隐藏处理，不保留旧平台默认回退。新版本发布不自动升级原分配，治理身份也不绕过字段权限。
