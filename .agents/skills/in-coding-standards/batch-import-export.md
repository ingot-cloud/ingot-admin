# 批量导入导出交互与 UI

新增或修改任何业务对象的批量导入、导出、模板下载，以及列表上的批量改关系（如批量变更部门）时遵循本篇。参考实现：

- 导入导出页：`plugins/org/src/pages/iam/members/workbook/`（`IndexPage.vue`、`components/ExportScopePicker.vue`、`workbookFile.ts`、`pollWorkbook.ts`）
- 批量改关系：`plugins/org/src/pages/iam/members/components/MemberBatchDepartmentDialog.vue`
- 我的下载：[download-center 当前规格](../../../specs/current/packages/download-center/spec.md)

## 1. 入口

- 列表工具栏放一个「批量导入/导出」，`kind: "primary"`，进入 `overflowGroup` 随宽度收纳。具备创建或导出任一权限才出现。
- 点击跳到**独立隐藏路由页**（如 `/org/iam/members/workbook`），不新增侧栏菜单，不用抽屉或对话框承载整个流程。路径和标题是模块常量（`MEMBER_WORKBOOK_PATH`、`MEMBER_WORKBOOK_TITLE`）。
- 需要选中行的批量操作：没选时禁用并给 `disabledReason`「请先选择成员」；选中的都不可操作时给具体原因（如「组织拥有者不能被暂停、移出或变更部门」）。

## 2. 导入导出页结构

自上而下：

1. `InPageFrame mode="page" surface="workspace"`；页头 `InPageHeader show-back`，高 53px、上下 12px、左右 20px，通栏不进限宽容器。返回与底部「取消」都回到列表页。
2. 正文用 `InFormContent`，设 `--in-form-content-max-width: 824px` 居中。整块正文由一个 `InLoading` 罩住提交过程。
3. 分段选项：高 32px、内边距 3px、1px 边框、圆角 6px；选项高 24px、圆角 4px，选中为主题色 8% 底 + 主题色字 + 500 字重。文案「导入新成员」/「导出并修改成员信息」这类动宾短语。**无权限的选项不渲染**，默认选第一个有权限的；切换选项清空已选文件。
4. 两张步骤卡：浅底 `var(--in-bg-color-page)`、内边距 24px、无圆角、间距 12px；标题 14px 常规字重，编号写进标题（「1. 下载导入模板」「2. 上传完善后的模板」），说明文字用次要色。
   - 第 1 张：创建模式「下载空白模板」（独立 loading，不占整页 busy）；更新模式「导出」打开范围对话框。
   - 第 2 张：标题右侧主色链接按钮「你的导入历史」；说明里提醒更新模板空列会清空字段。
5. 拖拽区：高 210px、1px 虚线、圆角 5px、表面底色；拖入时边框变主题色。中间放图标、「选择文件」按钮和已选文件名，下方写「可直接将文件拖拽到此处进行上传。支持格式：XLSX」。
6. 底部右对齐「取消」「导入」，按钮 80×32、圆角 6px；未选文件或当前模式无权限时「导入」禁用。

## 3. 文件选择

- `<input type="file" accept>` 与拖拽共用一个赋值函数；同时校验扩展名，不是 xlsx 时 `Message.warning("仅支持 XLSX")` 且不替换已选文件。
- 每次选择后把 input 的 `value` 置空，允许重复选同一文件。
- 同步返回的文件（模板、错误报告、一次性密码）用 Base64 → Blob → 临时 `<a download>` 下载，工具函数放页面目录（如 `workbookFile.ts`），不在组件里内联。

## 4. 导出

- 「导出」先打开范围对话框，标题如「编辑管理范围」：单选「全部 / 部分成员」，默认「全部」，每次打开重置。「全部」时宽 420px，「部分」时 840px，并在**同一对话框内**展开双栏选择，不再叠第二层弹窗。
- 双栏选择：左栏搜索（无 label、「请输入姓名」）、组织路径面包屑、「全选」（只作用于已加载项）、部门行（勾选 + 「展开」）与成员行（头像 + 姓名 + 摘要）、「加载更多部门/成员」、失败重试与空态；右栏只有已选数 > 0 时才显示「已选：N」与「清空」，每项可单独移除。分页、搜索、已选回显遵守 [entity-picker-interactions.md](entity-picker-interactions.md)。
- 选部门表示该部门及其下级中的对象。部门展开交给服务端：提交范围 ID，由后端在任务里收集。**不要**像现有成员导出那样在前端逐页拉成员拼 ID（那是历史做法）。
- 「部分」且未选任何项时「确定」禁用；范围内没有可导出对象时提示「所选范围内没有可导出的成员」。
- 提交前取最新资源版本作为 `expectedVersion`。提交成功即关闭对话框，用 `Confirm.success` 提示「导出任务已提交，文件生成后可在「我的下载」中下载。」，确认按钮「前往我的下载」（`router.push(DOWNLOAD_CENTER_PATH)`），取消按钮「知道了」。**页内不轮询、不直接下载导出文件**。文案用 `DOWNLOAD_CENTER_TITLE` 常量拼，不手写。

## 5. 导入

- 「导入」上传后在页内等待结果：轮询任务状态（间隔与次数是命名常量，成员为 1s × 60），超时抛「任务超时，请稍后在导入历史中查看」。轮询期间整页 `InLoading`。
- 结果对话框「导入结果」（480px）：「成功 X 人，失败 Y 人」；失败数 > 0 显示「下载错误报告」；创建导入且服务端标记可下载时显示主按钮「下载初始密码」，下载后立即把可下载标记置 false 隐藏按钮（一次性）。底部「确定」。成功数 > 0 时再给 `Message.success("成功导入 N 人")`。
- 「你的导入历史」对话框（640px）：最近 N 条，列为模式、状态、成功、失败、时间（`formatDateTime`）；状态用枚举标签而不是原始字面量。空态用 `noContentIllustration`、`image-size` 120、文案「暂无数据」，底部「我知道了」。

## 6. 批量改关系（两层确认）

以批量变更部门为准：

- 第一层选择对话框：宽 894px、`layout="pinned"`，标题加 `description` 说明后果（「确定后，已选成员的部门将全部替换为新部门」）。左右分栏 846×522：左搜索 + 树，右已选列表；不预填原关系；未选时右栏空白，勾选后才出现「已选：N 个部门」与清空；第一项为主项，可拖拽排序。未选时「确定」禁用。
- 第一层「确定」**不提交**，打开第二层确认框：宽 420px、无关闭按钮，用浅底流式标签列出本次真正提交的对象与新值（已排除拥有者、已移出等不可操作对象）。「取消」回到第一层并保留勾选；第二层「确定」才逐个调用单条接口。
- 全部成功：关闭两层、刷新列表、`Message.success("已更新 N 人任职")`。部分失败：`Message.warning("成功 X 人，失败 Y 人")`，有成功就刷新。

## 7. 检查清单

```
- [ ] 入口在工具栏、进隐藏路由页，不加菜单；按权限显隐
- [ ] 页头通栏 + InFormContent 824 居中；分段只显示有权限的选项
- [ ] 两张步骤卡 + 210 虚线拖拽区 + 右下角取消/导入（80×32）
- [ ] 只收 xlsx，未选文件时导入禁用，切换模式清空文件
- [ ] 导出：范围对话框默认全部、同框选择、提交即返回并引导「我的下载」
- [ ] 部门范围交给服务端展开，不在前端循环翻页拼 ID
- [ ] 导入：页内轮询、结果对话框、错误报告、一次性密码只下一次
- [ ] 批量改关系：选择层不提交，确认层列出真实提交对象再逐个提交
```
