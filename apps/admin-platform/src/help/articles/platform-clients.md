## 功能用途 {#purpose}

维护 OAuth 客户端的认证方式、授权类型、回调地址与令牌有效期。

## 前置条件 {#before-start}

- 具有客户端管理资格。
- 准备接入应用提供的回调地址、认证方式与授权类型。

## 操作入口 {#entry}

开发管理 → OAuth 客户端。

## 字段与规则 {#fields}

- 客户端名称、访问范围、认证方式和授权授予类型：按表单必填项维护。
- 重定向 URL：用于授权回调，与接入应用配置核对。
- 访问/刷新 Token 失效时间：单位为秒；刷新配置随刷新授权类型显示。
- PKCE、授权同意：在授权码类型下配置。

## 操作步骤 {#steps}

1. 点击“添加客户端”，填写名称、范围、回调地址、认证方式和授权类型。

2. 设置 Token 认证类型和有效期，按需配置刷新 Token、PKCE 和授权同意。

3. 保存后从结果对话框安全记录客户端 ID 与秘钥，点击可复制。

4. 通过详情维护可编辑配置，调整后按接入应用实际流程验证登录和刷新。

## 完成后的结果 {#result}

客户端配置更新。接入方需同步使用正确 ID、秘钥和回调地址。

## 常见问题与处理 {#faq}

**刷新相关字段为何没显示？** 仅在选择相应授权类型时出现。

**修改没有提交？** 未改变数据时会提示无需操作，确认是否真的修改了草稿。

**接入仍失败？** 核对回调地址、授权类型、范围、认证方式及有效期；提供错误码时隐去密钥和令牌。
