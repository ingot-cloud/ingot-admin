## 功能用途 {#purpose}

维护按业务标签划分的 ID 号段配置。

## 前置条件 {#before-start}

- 具有业务 ID 配置资格。
- 了解目标业务现有 ID 使用情况，避免与已分配值冲突。

## 操作入口 {#entry}

开发管理 → 业务 ID。

## 字段与规则 {#fields}

- 业务标签：必填，用于定位业务。
- 初始化 ID：必填，创建前与既有数据核对。
- ID 步长：必填，表示号段配置步长。
- 当前最大 ID、更新时间：查看配置状态。

## 操作步骤 {#steps}

1. 按业务标签搜索已有记录，避免重复创建。

2. 点击“添加业务ID”，填写业务标签、初始化 ID、步长和描述。

3. 保存后在列表核对配置；编辑既有配置前先与业务调用方确认影响。

4. 需要确认实际取号结果时，通过业务自身流程验证，不在配置页反复修改碰运气。

## 完成后的结果 {#result}

目标业务号段配置建立或更新，列表显示最新配置。

## 常见问题与处理 {#faq}

**初始化 ID 该填多少？** 由业务现有数据和迁移策略决定，帮助文档不提供通用默认值。

**步长是否代表每次返回的 ID 差值？** 本页维护号段分配配置，具体取号语义以业务接入为准。

**保存被拒绝？** 核对必填项、数值格式和服务端提示。
