## 功能用途 {#purpose}

维护不同作用域下的字典类型和字典项，区分业务存储值与展示文本。

## 前置条件 {#before-start}

- 具有字典维护资格。
- 清楚字典由哪些业务使用，以及所属平台、租户或应用作用域。

## 操作入口 {#entry}

设置 → 数据字典。

## 字段与规则 {#fields}

- 字典类型：作用域、编码、名称；租户/应用作用域需选择对应对象。
- 编码：最长 64 字符；名称最长 128 字符。
- 字典项：名称、value 和 label 必填；value 为业务存储值，label 为选择器展示文本。
- 排序：非负整数；备注最多 255 字符；extra 需为 JSON 对象。

## 操作步骤 {#steps}

1. 先创建或选择字典类型，确认作用域和归属。

2. 在类型下创建字典项，填写名称、字典值和展示文本，设置排序与状态。

3. 需要扩展属性时输入合法 JSON 对象，例如颜色或图标元数据。

4. 保存后回到实际使用该字典的业务页面检查展示；修改存储值前核对历史数据依赖。

## 完成后的结果 {#result}

类型及字典项在对应作用域内保存，业务读取按自身接入规则生效。

## 常见问题与处理 {#faq}

**value 和 label 能互换吗？** 不能随意互换，前者用于业务存储，后者用于展示。

**JSON 看起来正确却被拒绝？** 顶层必须是对象，不能是数组、字符串或空白解析错误。

**创建后编码为什么不能改？** 编码是稳定识别值，调整前需评估业务契约。
