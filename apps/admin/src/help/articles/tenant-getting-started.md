## 功能用途 {#purpose}

组织管理员可按“目录 → 角色 → 分配 → 应用 → 复核”的顺序完成基础配置。

## 前置条件 {#before-start}

- 已进入正确组织。
- 准备成员、部门、管理职责和需要开通的应用清单。

## 操作入口 {#entry}

组织管理；权限管理；应用管理。

## 字段与规则 {#fields}

- 全局账号与组织成员：一个账号可有不同组织的成员资格。
- 任职部门与用户组：描述组织关系或聚合人员。
- 角色与分配：角色定义能力，分配决定接收对象、范围和期限。

## 操作步骤 {#steps}

1. 先核对[组织信息](help:tenant-organization-settings)，确认名称、所有者与组织编号。

2. 维护[部门](help:tenant-departments)和[成员](help:tenant-members)，再配置任职、负责人和用户组。

3. 创建或检查[组织角色](help:tenant-roles)，明确操作、对象范围和字段权限。

4. 通过[角色分配](help:tenant-assignments)把角色授给成员或用户组；分工管理时配置[授权管理员](help:tenant-delegations)。

5. 在[应用管理](help:tenant-applications)核对可用人群，再用权限诊断和授权审计复核。

## 完成后的结果 {#result}

形成可维护的组织目录和明确授权。日后人员调动时，应同时检查任职、用户组和角色分配。

## 常见问题与处理 {#faq}

**添加成员后为什么没有业务权限？** 成员入职与角色分配是独立步骤。

**设置负责人就能管理部门吗？** 负责人是组织关系；还需要相应操作权限和对象范围。

**如何批量初始化？** 使用[成员表格](help:tenant-member-workbook)和[部门表格](help:tenant-department-workbook)，先少量校验再扩大范围。
