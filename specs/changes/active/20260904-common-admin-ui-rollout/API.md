# 接口：管理台业务页面 UI 迁移

## 来源

- 原始文件：无；本 change 不新增后端接口。
- 后端仓库：各页面沿用当前已经归档的接口契约。

## 服务与约定

- **服务**：沿用各业务域现有服务。
- **Base Path**：不变。
- **鉴权**：不变，继续使用 session、超级管理员判断和现有权限指令。
- **响应包装**：不变，继续使用统一 `R<T>`。

## 权限码

本 change 不新增、修改或移除权限码。按钮显隐、只读态和危险操作权限必须保持迁移前行为。

## 接口列表

本 change 不维护或复制既有接口字段表。实现时按页面对应的 current capability 与归档 change 查阅原接口契约；不得因 UI 迁移增加无业务必要的请求。

## 前端注意

- 查询条件、分页参数、排序、Query Key、`enabled` 条件和缓存失效范围保持不变。
- 页面级简单筛选是否即时查询，必须以本 change 的页面映射和原业务语义为准；不得统一改成每次输入即请求。
- 安全页面未访问 Tab 不发请求的行为必须保留。
- 写操作的防重复、确认文案、成功提示和生效时机必须保留。
- `InTableActions` 只接收页面提供的权限、禁用、确认和 handler 映射，不直接封装或替换业务 API。
- 字段显示偏好仅改变前端列呈现，不改变查询字段、排序、批量导出或权限检查，也不新增偏好接口。
- 本 change 不改变 bigint 字符串、时间格式、枚举值、DELETE 参数位置等既有接口约束。
