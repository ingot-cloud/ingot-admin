# 需求：授权审计游标分页与可读展示

> 增量变更。相对 `specs/current/base/platform-capabilities` 中“授权审计”的现有行为。

## 场景与页面

### 场景 1：浏览审计

- **角色**：持有审计读取权限的组织管理员或平台管理员
- **入口**：组织端“安全与合规 › 授权审计”；平台端“授权审计”
- **步骤**：打开页面 → 按时间倒序查看 → 点击“下一页”或“上一页”
- **预期结果**：每页条数可选 20、50、100；不显示总数和页码跳转；没有更多数据时“下一页”禁用；在第一页时“上一页”禁用。

### 场景 2：筛选

- **步骤**：选择操作者（成员选择器，单选）、对象类型（下拉）、变更类型、时间范围
- **预期结果**：任一条件变化后，回到第一页，并清空已走过的游标。

### 场景 3：从其他页面查看某个对象的审计

- **入口**：路由参数 `?targetType=role&targetId=88`
- **预期结果**：筛选区显示可移除的标签“已限定对象：角色 · 研发管理员”。名称来自本页返回的 `references`；如果本页没有这个对象的引用，显示“已限定对象：角色”。移除标签后清空 `targetId`。

### 页面结构

| 列 | 内容 |
|---|---|
| 时间 | 当地时间 |
| 操作者 | 成员名称；无权查看时显示“无权查看的成员”；已移出时显示“{名称}（已移出）”或“已移出的成员” |
| 操作 | 变更类型，点击打开详情 |
| 目标 | “{类型} · {名称}”；规则同上；单例类目标只显示类型文案（例如“目录策略”、“成员导入”） |
| 变更摘要 | 完整差异，例如“名称：研发部 → 研发中心；状态：启用 → 停用”。创建时只写新值，移除时只写原值。列内最多显示两行，悬停后的提示按“每个字段一行”完整展示 |

详情抽屉：

- 审计 ID、追踪 ID：保留，可一键复制。
- 操作者：只显示名称，不再显示“成员 ID”。
- 角色分配、来源委派：显示引用名称。
- 关联版本：只显示对象和版本号；初始化策略的版本 ID 显示为“已创建”。
- 差异表：逐字段显示格式化后的变更前和变更后，结构化内容展开为多行可读文本。

## 验收标准

- [ ] 列表、悬停提示和详情中都不出现成员、角色、部门等内部 ID（审计 ID、追踪 ID 除外）。
- [ ] 每种 AuditField 都有可读格式；未知字段显示字段编码和原始文本，不报错。
- [ ] 历史数据兼容：批量任务的 NAME 编码不显示为“名称：member-workbook”；平台委派的占位接收对象显示为“接收对象已调整（未记录明细）”。
- [ ] 上一页、下一页和每页条数切换正确；筛选变化后回到第一页；切换组织或身份后，清空游标和详情。
- [ ] 无权限不发请求；错误、无权限、空结果、筛选无结果四种状态仍然分别展示。
- [ ] 平台端与组织端行为一致。
