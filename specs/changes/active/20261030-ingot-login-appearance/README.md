## 配色策略配置增量

2026-10-30 用户要求默认 light 并支持指定 auto/dark/light，已完成。租户与平台登录站分别在 `apps/auth/.env`、`apps/auth-platform/.env` 配置 `VITE_APP_LOGIN_COLOR_SCHEME=light`；可由对应环境文件覆盖。公共 `useAuthAppearance` 接收 `AuthColorScheme`，禁用本地主题存储干预，空/非法值回退 light。auto 继续响应系统配色变化。
