# 需求与验收

1. 平台与租户登录页共用布局、配色、字体、控件和状态，仅保留已有标题、描述及认证流程差异。
2. 登录 Logo 使用管理台现有 `in-light-framed.svg` / `in-dark-framed.svg`；加载使用已有 Ingot 动态 SVG。页面图标随主题选择同款品牌资源。
3. 默认浅色使用品牌色 #3370ff、画布 #f5f5f5、白色工作面、正文 #1f2329、次级文字 #646a73、边框 #dee0e3；深色沿用管理台现有 Token。样式通过共享变量表达。
4. 桌面左侧为浅色品牌区和 CSS 几何装饰，右侧登录面板最大宽 420px；面板按内容撑高，采用细边框、轻阴影、12px 圆角。窄屏单栏，矮屏可自然滚动，版权不覆盖内容。
5. 标题 24px、正文 14px、辅助文字 12px；输入和主按钮 48px，控件圆角 6px，间距为 4px 基线。输入有可见标签、placeholder、自动填充语义、焦点状态。忘记密码为独立按钮，维持联系管理员提示。
6. 组织选择沿用同一品牌面板，返回和组织项支持键盘；长组织名可读，列表局部滚动，窄屏不溢出。错误页、加载遮罩、消息和挑战弹层使用相同语义颜色。
7. 两登录站通过 `VITE_APP_LOGIN_COLOR_SCHEME` 指定配色策略：`light` 固定浅色、`dark` 固定深色、`auto` 跟随系统并响应系统变化；默认、空值与非法值均为 `light`。配置是登录站配色来源，不读取或写入历史 `vueuse-color-scheme`，确保旧深色偏好不能覆盖配置。不新增页面切换入口或跨域偏好协议。
8. BFF 事务、CSRF、信封加密、412 挑战、READY 跳转、单组织自动进入、多组织选择、过期恢复及账号锁定语义保持原契约。

## 验收

- 用户分别从租户与平台管理台发起登录，检查 Logo、配色、排版和按钮状态一致。
- 用户在宽屏、窄屏（含 320px）与矮屏检查页面无裁切、横向溢出、版权遮挡；检查组织长名称与组织列表滚动。
- 用户分别配置 light、dark、auto，检查 Logo、输入、错误页、遮罩和挑战弹层可读；auto 跟随系统切换，缺省/非法值回退浅色，旧本地深色偏好不覆盖配置。修改环境变量后重启开发服务，生产重新构建。
- 用户检查密码可见切换、Tab 焦点、Enter 登录、忘记密码、提交中、错误密码、412、事务失效及多组织选择/返回。
- 开发侧完成定向静态检查与构建，真实联调及视觉结果由用户确认后再更新 current 和归档。
