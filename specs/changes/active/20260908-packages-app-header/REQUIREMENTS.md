# 需求：顶栏五区布局与 APP 配置扩展

## 场景与页面

- **角色**：管理台 APP 开发者、已登录用户。
- **入口**：APP 启动配置和 layout.main 默认顶栏。
- **配置场景**：开发者声明品牌、大类入口、搜索组件、功能组件和用户菜单，无需复制核心顶栏。
- **使用场景**：用户收起侧栏、调整窗口宽度、选择大类菜单、展开分组面板、操作小部件或用户菜单，入口保持可达。
- **结构**：从左至右为品牌、大类菜单、搜索、功能小部件、用户入口五区。

## ADDED

### REQ-A001：APP 配置入口

- [ ] APP 可配置五区内容；共享行为由 admin-core 提供。
- [ ] 不传新配置时保留品牌、搜索开关、全屏、设置及现有用户菜单。
- [ ] 小部件、用户菜单按配置数组顺序排列；显式数组替代默认列表，空数组清空列表。
- [ ] 可见、禁用、选中态和角标变化能响应更新；组件、回调不持久化。

### REQ-A002：大类菜单与分组面板

- [ ] 入口支持直接操作或点击展开分组菜单，支持图标、标签、可见和禁用状态。
- [ ] 以实际可用宽度决定直出数量，预留更多按钮；存在可见入口时至少保留一个入口。
- [ ] 优先保留当前选中入口，其余按配置顺序填充；无选中项时从首项开始。
- [ ] 未直出入口进入更多浮层，分组入口在更多浮层中仍可进入分组内容。
- [ ] 分组面板宽屏多列、窄屏单列，长内容在受限高度内滚动。
- [ ] APP 提供选中态和选择回调；核心不自行分组侧栏、跳转业务路由或持久化系统选择。

### REQ-A003：功能小部件

- [ ] APP 可选择内置全屏、设置，配置图标操作或自定义 Vue 组件，并控制顺序、显隐、禁用和角标。
- [ ] 功能区宽度跟随内容，变宽时推动搜索向左并减少大类直出项。
- [ ] 窄屏时从右向左收进更多浮层，收纳后功能仍可操作；自定义组件不重复挂载。

### REQ-A004：用户区配置

- [ ] 用户入口独立位于最右侧，默认保留当前头像及下拉入口。
- [ ] APP 可配置入口展示，选择、排序和隐藏切换组织、修改密码、退出登录，并添加自定义操作及分隔线。
- [ ] 内置项复用原有逻辑，自定义项调用 APP 回调，隐藏项不参与展示。
- [ ] 用户菜单为空时保留用户信息入口展示，不提供无内容的下拉交互。

## MODIFIED

### REQ-M001：UI 基础设施 REQ-002 → 五区响应式顶栏

原四区顶栏拆分为五区，替代导航及操作区域依赖横向滚动、固定断点隐藏入口的默认行为。

- [ ] 桌面端品牌区右边界与侧栏右边界对齐，包含 gutter 和顶栏内边距影响。
- [ ] 侧栏展开显示 Logo 与标题，收起仅显示 Logo，宽度动画同步。
- [ ] 窄屏延续侧栏 overlay 模式，品牌显示导航开关与 Logo。
- [ ] 导航为空时不显示入口或更多按钮，搜索仍靠近功能区。
- [ ] 放不下一个菜单与完整右侧内容时，先将搜索变图标，再收纳小部件；长菜单标签省略。
- [ ] 375px 窗口仍可访问导航开关、至少一个可见大类入口（如有）、搜索（如启用）、小部件和用户入口，无整页横向滚动或重叠。

### REQ-M002：搜索与主题扩展兼容

- [ ] 搜索继续使用 settings.showSearch 及原有运行时设置，不引入第二个显隐配置源。
- [ ] 支持占位文案与 APP 自定义搜索组件，紧凑入口点击后在浮层展示搜索，切换形态不丢失输入状态。
- [ ] 保留 shellSlots 和主题 header 部件替换；自定义主题可以读取顶栏配置。
- [ ] 未接入新配置的 APP 可正常使用默认顶栏。

## 通用验收

- [ ] 浮层支持键盘操作、Escape 关闭、关闭后焦点恢复，禁用项不可触发。
- [ ] 字体加载、长标题、角标变化、动态显隐、侧栏动画及窗口变化均能重新分配宽度，无反复抖动。
- [ ] 在 1440、1280、1024、768、375px 验证展开/收起、搜索关闭、多小部件、分组菜单及浅色/深色主题。
- [ ] 不出现未实现的正式业务入口，不新增后端接口或业务联动逻辑。
