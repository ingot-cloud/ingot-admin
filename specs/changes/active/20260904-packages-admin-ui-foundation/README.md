# 20260904-packages-admin-ui-foundation

> 状态：implementing

## 协作模式

一人全栈。本 change 为纯前端共享 UI 基础设施变更，不新增或修改后端接口。

## 背景与动机

现有管理台已经在 `@ingot/admin-core` 提供布局、菜单、容器、表格、抽屉与弹窗，但视觉变量和组件规则不完整，部分页面仍依赖硬编码颜色、字号、阴影和局部间距。主框架采用高饱和蓝色顶栏，表格横向滚动又容易被多层 `overflow-x-hidden` 截断，难以形成稳定、可复用的后台体验。

2026-09-04 对飞书管理后台进行了多轮只读采样。初版实现视觉验收未通过后，用户决定缩小下一批范围：本轮只复核“成员”页面内容工作区，对应 `InSplitLayout` 与 `InTable`。采样覆盖页面头、260px 左侧部门栏、折叠按钮、右侧标题/筛选/操作区、字段显示设置、表头、固定操作列、横向滚动和分页。

飞书成员页在窄宽度下会自动隐藏左侧部门栏。进一步复测确认，工具栏中的“邀请成员”“添加成员”始终直出；“批量导入/导出”“批量变更部门”“批量操作离职”组成原子折叠组，空间不足时整组替换为固定操作左侧的“…”菜单，空间足够时整组一次性展开。本 change 复刻这一组级响应行为，不采用逐个按钮收纳。

2026-09-05 按用户要求再次聚焦飞书管理后台的全局左侧导航。实测确认导航面板与页面画布同色，展开/收起宽度为 236px / 52px；菜单列表和底部控制区是两个独立区域，列表滚动时“收起导航”始终固定在侧栏底部。现有 Phase 02 的完成记录保留，本次差异作为 Phase 07 单独修订和验收，不回写已完成任务。

本 change 先建设 Ingot 自有的管理台设计基础，不批量迁移业务页面。后续页面迁移由关联 change `20260904-common-admin-ui-rollout` 承担。

## 目标

- 在 `@ingot/admin-core` 建立完整、语义化、可主题化的管理台设计 Token。
- 将管理台框架调整为白色顶栏、灰色画布/侧栏、白色工作面以及内容区域独立滚动的布局。
- 在已有框架高度约束内，让 `InSplitLayout` 固定 header，并让左右内容区拥有明确的高度与滚动边界。
- 为 `InSplitLayout` 增加成员页式 260px 左栏、分隔线折叠按钮和窄宽度自动收起行为。
- 移除 `InTable` 内置刷新按钮，将字段设置等能力改为按需导入的独立工具组件。
- 为 `InTable` 增加可组合 tools 区，以及“固定操作 + 原子折叠组”的自适应操作组件。
- 对齐成员页的右侧标题、工具栏、表头、紧凑数据行、固定操作列、滚动条和分页布局。
- 补强全局侧栏的菜单层级、收缩态、独立滚动区与固定“收起导航”控制区。
- 保留 Ingot 品牌，不复制飞书商标、插画、专有字体或图标资产。
- 为后续四个官方业务插件的页面迁移提供稳定共享能力。

## 范围

### In Scope

- `packages/admin-core/src/styles/` 的颜色、排版、间距、圆角、阴影、层级、动效和控件尺寸 Token。
- Element Plus 变量映射及现有明暗主题兼容。
- `layout.main` 的顶栏、侧栏、面包屑、内容滚动与响应式行为。
- Phase 06 补强涉及 `InSplitLayout`、`InTable`、`InTableActions`、`InColumnSetting` 及其类型、fixture、测试和文档。
- 新增 Phase 07 只涉及全局侧栏对应的 `layout.main`、`InMenu`、`InSubmenu`、侧栏 Token、偏好状态、fixture、测试和文档。
- 全局加载、空态、错误态、禁用态、焦点态和减少动效模式。
- `@ingot/admin-core` 单元测试、组件契约测试、视觉验收基线及开发文档。
- 保持 `bootstrapAdminApp` 现有 branding/settings 配置兼容。

### Out of Scope

- 批量修改 `plugins/platform`、`plugins/org`、`plugins/member`、`plugins/security` 业务页面。
- 修改路由、菜单数据结构、权限码或 canonical viewPath。
- 新增组织、成员、角色等全局语义搜索接口；本次只提供搜索入口和扩展契约，继续复用现有菜单搜索能力。
- 修改业务接口、请求参数、响应结构或 TanStack Query 行为。
- 在 Phase 07 中调整全局顶栏、面包屑、抽屉、弹窗、Tab、普通详情页框架或业务菜单数据。
- 复制飞书品牌资产、营销插画、Logo 或专有图标。
- 将移动端作为完整业务操作端；小于 1024px 仅保证框架可达和内容不丢失。

## 风险与依赖

- 共享组件修改会影响所有组合 `@ingot/admin-core` 的 App，必须保持公开属性、插槽和事件的兼容或提供迁移期兼容层。
- 调整滚动容器可能影响固定表头、返回顶部、抽屉和页面缓存恢复位置。
- `InSplitLayout` 高度与滚动契约变化可能暴露旧页面未设置 `min-height: 0` 的问题，必须保留兼容 fixture。
- 自适应操作收纳若直接移动或复制任意 VNode，可能导致组件状态、焦点和 Popover 失效；只允许配置型 action 自动收纳，自定义复杂工具保持显式插槽控制。
- 字段显示设置使用前端持久化，不得把权限字段、操作列等必选列错误隐藏。
- Element Plus 默认变量与 Ingot Token 存在双向覆盖风险，需要明确单向映射。
- 暗色模式若无法同步达到验收质量，不得静默退化；应在实现前确认保留同步发布或拆到后续 change。
- 关联 rollout change 必须等待本 change 的共享组件契约稳定后才能实施。
