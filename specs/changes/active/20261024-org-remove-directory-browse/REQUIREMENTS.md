# 需求

## 场景

组织管理员从工作台进入时不再看到通讯录。配置成员字段时只设置后台管理场景。

## 规则

- 删除 viewPath `org.iam.directory` 对应页面。
- 成员访问策略页只保留字段权限。场景固定为后台管理，不提供普通通讯录、通讯录查询和预览。
- 没有通讯录读权限的菜单不再出现。页面不保留指向已删除接口的调用。

## 验收

- 路由表没有 `org.iam.directory`。
- 成员访问策略不请求 `/policies/directory` 和 `/policies/preview`。
- 字段规则保存的场景为 `MANAGEMENT`。
- 成员、部门页面的接口调用保持不变。
