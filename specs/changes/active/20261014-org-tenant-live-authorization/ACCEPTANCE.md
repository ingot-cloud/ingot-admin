## 数据与手动路径

沿用后端最小数据集：A/B组织拥有者、普通成员、仅委派管理员、平台维护员；共享多历史版本、私有和旧差异角色；直接/组/委派及到期来源；多个资源与字段。至少两租户窗口同时在线，平台改共享当前权限后观察当前会话自动刷新并请求真实接口。

租户路径：角色列表 → 共享只读 → 创建私有 → 编辑当前权限 → 分配成员/组 → 角色增删权限 → 缺范围提示和普通编辑补齐 → 资源委派 → 仅委派身份分配 → 撤销/到期 → 转交拥有者。

平台路径：共享创建/预览/保存 → 两组织自动生效 → 自有角色历史/字段/批量任务回归。布局使用宽/窄工作区与滚动、只读/错误/空状态，禁止仅列表或空按钮事件宣称页面完成。
