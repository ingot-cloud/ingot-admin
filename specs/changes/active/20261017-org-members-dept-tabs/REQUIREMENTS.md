# 需求：成员与部门两个子页面

接管 [UI03 成员与部门](../20260913-base-iam-admin/INTERACTIONS.md) 的页面布局，业务规则（账号与成员分离、字段可见性、capabilities、导出三步、非空删除）保持不变。

## 场景与页面

### 场景 1：按部门查看成员

- **角色**：具备 `iam-tenant:member:read` 的租户管理员或授权成员
- **入口**：组织管理 → 成员与部门 → 成员
- **步骤**：左树搜索并选择部门；表头显示部门名与人数；按手机号/邮箱/状态筛选；多选后批量变更部门/离职/导入导出；添加、详情、暂停/恢复/移出
- **预期结果**：交互对齐 contacts/user；左栏无部门增删改按钮

### 场景 2：维护部门树

- **角色**：具备 `iam-tenant:department:read` 的身份
- **入口**：组织管理 → 成员与部门 → 部门
- **步骤**：树形表搜索部门名；新建、添加子部门、打开详情编辑、删除空部门
- **预期结果**：交互对齐 contacts/dept；人数来自 `memberCount`；无读权限时侧栏不出现部门菜单

### 页面结构

- 两个独立路由：`org.iam.members` / `org.iam.departments`，各用 `in-page-frame` + `in-split-layout`
- 成员：可折叠左树、标题计数、账号状态 `InPicker`、列设置、头像+显示名、状态标签
- 根部门（无 `parentId`）左侧 24×24 圆角矩形组织 logo；无 logo 时用部门名首字、主题色底、白字；根节点不占展开箭头槽
- 子部门左侧 14px `OrganizationOutlined`；未选中与正文同色；主部门与直属子部门平级；树行高 40px
- 左栏白底铺满；搜索框与部门树左右 20px 对齐；行内左右 8px，展开箭头前后各 8px；根 logo 到名称 12px，子图标到名称 8px
- 选中部门背景 `rgb(240, 244, 255)`，文字与图标用主题色；默认文字色走 body 文本色
- 成员左树不放新建部门；不要求与飞书功能对等，视觉对齐即可
- 成员表姓名列固定最前，30px 圆形头像 + 字重 500 正文色姓名；默认显示：姓名、账号状态、手机号、部门、登录手机号；默认隐藏：邮箱、入职时间、更新时间
- 成员表行多选；工具栏从左到右：批量操作离职、批量变更部门、批量导入/导出、添加成员。仅添加成员 `overflow: never`，其余 `auto` 同组随宽度收纳
- 部门：树形表、名称搜索、列设置、多选、批量删除、批量导入/导出、新建部门、详情/添加子部门/删除
- 部门表默认列：部门名称、部门人数、操作；排序默认隐藏；不补负责人、部门群
- 部门表对齐飞书：主部门顶格无展开槽、无详情；子部门缩进展开；行高 56px
- 部门抽屉：创建用 `in-drawer`，详情用 `in-detail-drawer`

## 验收标准

- [ ] 成员页与部门页是两个路由，互不挂载对方表格
- [ ] 无 `iam-tenant:department:read` 时侧栏不出现部门菜单；旧 `?tab=departments` 进入成员页时重定向到部门路由
- [ ] 成员左树可搜索并默认选中根部门；主部门与直属子部门平级
- [ ] 根部门显示 24×24 圆角矩形组织 logo 或首字头像且不占展开箭头槽；子部门显示 14px 组织图标
- [ ] 成员表姓名列最前，30px 圆形头像；默认列含姓名、账号状态、手机号、部门、登录手机号；邮箱、入职时间、更新时间默认隐藏
- [ ] 成员表标题为「当前部门名 + 共 N 人」
- [ ] 成员左树无新建部门，行高与选中态对齐飞书视觉
- [ ] 字段不可筛选/不可见时不展示对应筛选项或列值
- [ ] 部门人数缺失显示 `-`
- [ ] 部门操作按 capabilities 禁用并给出原因
- [ ] 导出仍走创建 → 状态 → 下载
- [ ] 左树与部门页消费接口树，无分页拼树、无 `size: 200`
- [ ] 部门表主部门顶格、子部门缩进；主部门无详情操作
- [ ] 成员表有行多选；工具栏飞书顺序：批量操作离职、批量变更部门、批量导入/导出（`overflow: auto` 同组收纳）、添加成员固定直出
- [ ] 部门表有行多选（主部门勾选 off）；工具栏飞书顺序：批量删除、批量导入/导出、新建部门，全部 `overflow: never`
- [ ] 选中后第一列表头按框架约定显示「列名 · 已选 N 条」，未选中只显示列名
