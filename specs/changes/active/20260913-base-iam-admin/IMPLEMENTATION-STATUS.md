## 2. 逐操作与证据口径

[IAM-INTEGRATION](./IAM-INTEGRATION.md) 保留原 I001–I161 与后端 operationId，最后一列记录API符号、消费落点或明确缺口，并关联U任务。标记“调用链已接”只表示源码已连接，不表示UI交互、DTO和运行效果全部正确；“仅封装”必须继续完成消费；“待接入”不能因为存在旧PMS页面而算完成。I001/I002 已在 admin-core 接通，不得再标待接入。

实际后端以同级 ingot 的 `/v1` 控制器和本change契约为准；快照96路径/161操作不是完成率。BFF与OSS/Security/Member等依赖另见矩阵补充表。内部RPC由相应服务消费，不为覆盖数字创建管理页面。

前端后续必须适配本次范围内全部已实现管理功能。已有半完成页面必须达到INTERACTIONS第5节与 DESIGN §9.1；发现后端契约或能力缺口，记录具体操作、失败行为及后端任务，不自行省略业务功能。
