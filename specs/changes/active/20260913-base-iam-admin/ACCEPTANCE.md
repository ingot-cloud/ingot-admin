# 前端验收

当前未实施、未执行测试。验证使用普通成员、研发只读管理员、受限委派管理员、租户所有者和平台管理员，不能只以超管验收。

| 编号 | 场景 | 预期 |
|---|---|---|
| A01 | 平台/租户导航及隐藏目录 | 各最多四个一级，诊断/版本/范围为内部入口；无权菜单不显示，URL直达受拦 |
| A02 | bootstrap、切组织、旧请求迟到 | 一致版本初始化，旧数据/菜单/草稿清除，迟到响应不能回填 |
| A03 | 研发只读成员列表/详情 | 仅研发及下级，手机脱敏，无创建编辑移出导出；不自行行过滤 |
| A04 | 创建租户/应用开通 | 最小初始化预览，无复制模板，不把开通或所有者当全部业务授权 |
| A05 | 共享直接用、差异新增移除替换/恢复 | 无读取触发写，标签及最终效果正确；移除只影响本角色 |
| A06 | 平台升级、旧引用、三方冲突、409 | 不自动升级既有授权，冲突未解不提交，草稿保留并重新预览 |
| A07 | 受限分配/委派、范围期限超限 | 只选允许版本与对象，不拼接委派；批量失败不误报部分成功 |
| A08 | 多部门/无部门成员、组引用与变更 | 按服务端对象能力展示；组修改影响可预览，禁止间接扩权 |
| A09 | 通讯录允许/禁止/默认/本人/祖先 | 树搜索详情人数选择器一致，不泄露隐藏分支 |
| A10 | 多字段策略、完整编辑、脱敏/隐藏提交 | 不返回/渲染原值，表单无脱敏回传，不从原值检索推断 |
| A11 | 到期、403撤权、前台恢复 | single-flight刷新，操作响应式更新，无旧权限短路 |
| A12 | 503/404/离开/请求失败 | 明确错误和重试，不伪装空/游客；编辑离开确认，mutation不自动重复 |
| A13 | 诊断与审计 | 来源可追踪且受限制，无模拟执行，导出受独立权限 |
| A14 | 清理PMS/构建/插件边界 | IAM端点生效，Member/认证协议不误改，类型/边界/构建通过 |
| A15 | 迁移后新环境登录 | 清旧会话与授权缓存，按后端迁移映射展示资料，不增加前端迁移面板 |

组件测试覆盖向导步骤、差异生成、scope参数、field payload、响应式按钮、错误状态；集成测试覆盖 query/contextEpoch 和预览竞态；Playwright/E2E 在真实后端覆盖 A01–A15。Mock 不能替代真实授权范围验证。
