# IAM 前端需求

## 1. 用户场景与页面归类

平台目录：组织与租户（租户管理及详情）；应用与配置（应用、套餐、共享角色、字典）；平台管理（人员、角色与授权）；安全与运维（现有安全、会话、事件及运维）。

租户目录：组织管理（成员与部门、组、设置）；权限与应用（角色与授权、应用）；安全与合规（成员权限、安全设置、审计）；工作台（应用入口、普通通讯录）。详情 Tab、诊断、资源、范围和版本不新增一级菜单。没有可见子页隐藏父级。

详细逐页流程以 [INTERACTIONS](./INTERACTIONS.md) UI01–UI12 为准，本文件补充前端验收约束。

## 2. 核心需求

- R01：平台/租户上下文明示，不能靠改变 tenantId 查询切换。切换清除旧域菜单、查询、详情、草稿与迟到响应。
- R02：新建租户全页向导：资料、所有者、应用、预览。展示最小初始化结果，不提供批量复制角色。所有者治理不被表现为全部业务操作。
- R03：共享角色只读，可直接分配或基于固定版本定制；系统治理角色不可定制。租户角色只存差异，不让浏览角色目录产生创建请求。
- R04：角色向导：基本信息→操作→逐操作范围→预览发布。只选查看、当前全选、查看/编辑独立、不自动授予未来操作。
- R05：定制角色展示最终效果与本组织调整、基础来源标签、恢复基础；移除仅本角色不授予，不能文案误导为全局禁止。
- R06：升级显示三方差异、冲突、实际效果和待升级授权；默认不选既有授权，冲突不解决不能发布。
- R07：分配抽屉选择人/组、固定角色版本、管理范围与期限、预览；按资源能力显示范围，多个接收者所属部门分别展开。
- R08：委派管理员只分配限定角色，不能创建角色或下级委派。角色白名单、接收人员、逐操作范围上限和单次分配最长时间缺一不可；委派自身起止时间可留空。
- R09：成员详情默认只读；对象级操作看后端能力，字段权限决定数据展示与表单可编辑。组织成员不展示全局密码重置为普通资料操作。
- R10：用户组显示来源、有效成员及引用；修改先预览影响，超限不得提交。应用人群配置明确不等于业务授权。
- R11：通讯录默认/允许/禁止规则及成员预览；字段矩阵支持场景、查看者、目标、展示和编辑。全部预览来自后端，不在浏览器重做策略引擎。
- R12：诊断只解释，不模拟执行；审计展示安全差异。普通通讯录与管理页面调用不同端点，不显示后台编辑按钮。
- R13：所有表单处理原子提交、未保存离开、409 冲突、403 撤权、503 重试、404 不存在或不可访问。
- R14：菜单与 ACTION、对象能力、字段权限分工；客户端不按角色名或本地部门计算放行，后端最终鉴权。
- R15：一次版本一致的 bootstrap 替换原 info/menus/permissions 分开获取；权限过期后使用前刷新，前台恢复/403 重验。
- R16：全新系统启用后重新登录，不继承旧 PMS 授权缓存；前端无数据库迁移功能，不保留旧接口双写。

## 3. 交互默认

全页向导用于租户、角色创建和复杂升级；日常详情采用既有 InDetailDrawer，只读后进入编辑。分配采用大抽屉，复杂步骤保持固定页头/页脚，窄屏转全宽。

编辑草稿仅内存存放，不保存敏感资料或授权草稿到 localStorage。只在同一身份的 409/撤权时保留当前输入供检查；切换身份或退出清除所有旧上下文草稿。

无功能隐藏；对象越界禁用并解释；业务状态限制显示业务原因。503 阻止受保护操作并标记数据不可用，不显示成功空列表；首次无数据时显示错误状态。隐藏字段不渲染，脱敏值不作为表单提交值。

## 4. 非目标与验收

不增加空安全功能、额外一级菜单、前端规则执行器、后台跨租户模拟登录、会员系统授权重构。

- [ ] 逐页交互 UI01–UI12 及本文件 R01–R16 均通过 ACCEPTANCE。
- [ ] 后端字段和操作 code 未确认的接口不冒充可用，不按猜测完成集成。
- [ ] 全新系统初始化由后端验收；前端提供新系统登录、权限和异常场景联调证据，不要求旧库迁移。

## 5. 双入口与全量补齐增量（2026-09-16，draft）

- R17：两个独立登录 App、一份 admin 源码两部署；同主域四 HTTPS origin，各自品牌、构建配置和产物。
- R18：登录 domain 由 BFF 固定，失败不跨域；零租户失败、单租户自动完整认证、多租户选择；平台无候选页。
- R19：两域同时在线；普通退出独立。切租户重新认证成功后更新当前应用身份，失败或取消保留原会话，旧响应不回填。
- R20：事务绑定浏览器及应用；不向 BFF 传 returnTo/重定向 URL；登录站经一次性交接到目标 admin 建立正式会话，不共享父域 Cookie。深链仅本站相对 path。
- R21：错误/取消/退出页不接受任意返回地址；预认证不能加载管理接口；初始改密、挑战、锁定和 Member 语义保留。
- R22：账号治理、本人资料/密码、字典/发号/社交和成员导出状态均按当前契约对齐；补齐向导、Tab、冲突与非超管操作，逐操作矩阵必须有真实落点和证据。
- R23：bootstrap 域校验；无业务菜单显示无可用功能而非登录失败；四站点部署验证与 L01–L12 纳入交付。

BFF 的输入输出与错误以 BFF-LOGIN 为准；本轮不实施代码，不把新契约当作已有能力。
