# 飞书风格、阅读交互与配图验收

## 1. 参考与边界

参考页面（2026-11-03核对）：

- [飞书帮助首页](https://www.feishu.cn/hc/zh-CN/)：淡蓝渐变搜索区、明确标题、圆角大搜索框、入门卡片与分类入口。
- [飞书企业管理后台分类](https://www.feishu.cn/hc/zh-CN/category/6933474571089608732)：按功能组织的主题与文章。
- [图文文章参考](https://www.feishu.cn/hc/zh-CN/articles/360044088133)：左侧分类树、浅蓝选中文章、面包屑、大标题、适用对象提示、分步骤正文、章节目录与图文混排。
- [帮助中心使用方式](https://www.feishu.cn/hc/zh-CN/articles/360049067685)：通过关键词或目录寻找说明。

用户提供的飞书管理后台截图用于参考顶栏问号入口。含账号及组织信息的原图保留在会话附件和本地参考目录。

本页后续尺寸为**本项目实施目标**，用于保证与飞书相近的阅读比例，不宣称为飞书页面测量值。保留Ingot品牌、已批准的业务布局、明暗主题及权限规则。帮助页不加入飞书的营销横幅、销售入口、登录按钮或智能助手。

## 2. 布局与视觉目标

### 全局阅读壳

- 当前origin内独立帮助布局，顶部64px，高度计入sticky偏移；品牌/帮助中心、当前端标识、文档搜索及返回管理台。不同端始终明确显示“租户端”或“平台端”，不提供切换内容端的控件。
- 桌面内容区最大1440px居中，常规水平内边距32px；小屏16px。白/浅灰底、深灰正文、蓝色链接及柔和蓝色选中底，细边框、克制阴影。
- 浅色模式参照飞书；dark使用项目语义Token转换背景/边框/正文与选中态，不用滤镜反转截图，不改变用户已选主题。
- Token统一管理，不在每个业务页复制颜色/尺寸。交互反馈轻量，尊重prefers-reduced-motion。

### 首页

- 顶部淡蓝渐变搜索区，桌面目标高度约240px；标题30/42px、居中，文案为“有什么可以帮你？”；端标识在帮助头部持续可见。
- 搜索框桌面最大640px、高52px、圆角26px，带搜索图标，placeholder“搜索功能或使用问题”，按钮/回车均可提交。窄屏宽度自适应。
- 快速入门最多3张卡，卡片浅色背景、标题、简述和方向提示；卡片整体可点，hover/focus有清晰反馈。
- 下方功能分类使用图标、名称、简述的整项入口；常见问题及近期更新为轻量文章列表。内容来自本域静态编排，不显示虚构阅读量。
- 卡片桌面3列、中屏2列、窄屏1列，按可用内容宽度调整；不把首页做成管理CRUD表格。

### 分类、搜索与文章

| 区域 | 桌面目标 |
| --- | --- |
| 左侧分类树 | 宽240px、右细边框，顶部固定在阅读头下；可独立滚动，选中文章浅蓝底/蓝字 |
| 正文区 | 余下空间居中，文章正文最大800px，左右保留24～32px间距，min-width:0 |
| 右侧本篇目录 | 宽200px，sticky，超长时内部滚动，不盖住正文 |
| 文章标题 | 32/44px、较粗；长标题换行，无截断省略 |
| 正文与层级 | 正文16/28px，h2为24/34px，h3为20/30px，元信息13/20px |
| 节奏 | 段落间约16px，大章节间约32px；列表与图片上下留白一致 |
| 提示块 | “谁能操作/前置条件”浅蓝提示；注意/风险用相应语义色、图标与文字，不只靠颜色 |
| 配图 | 正文宽度内等比例居中，细边框/小圆角；图注在下方，文字清晰可辨 |

文章顶部展示面包屑、标题、阅读时长、更新时间与适用对象。末尾显示相关说明、前后篇及有授权目标时的“前往功能”。元信息时间遵循当地展示规范。

搜索结果为标题、分类路径、命中摘要和更新时间组成的文章列表；匹配词用蓝色/浅色高亮，不能把搜索文本当HTML执行。页码控件位于结果列表后，默认20项（本地分页）。

### 响应式

- 可用宽度≥1200px：分类树、正文、大纲三栏。
- 768～1199px：左侧分类仍可收起，大纲改为正文顶部可展开“本篇目录”；不挤压正文到不可读。
- <768px：分类树改为“浏览目录”按钮打开抽屉，文章单列；目录按钮与搜索不重叠；大纲折叠；首页单列。搜索可在紧凑头部展开。
- 375px宽度无页面横向滚动；表格和代码段仅自身区域可横向滚动，图片不超正文。

## 3. 交互契约

| 操作 | 预期反馈 |
| --- | --- |
| 点击全局帮助图标 | 进入当前端首页；不随当前业务页暗中变成另一篇文章 |
| 业务页点击“使用说明” | 按已发布viewPath映射打开主说明；动作教程可打开明确articleId |
| 点击分类标题/展开三角 | 分类标题进入分类页；独立三角只收展，展开状态与当前文章祖先保持一致 |
| 文章直接访问/搜索跳入 | 自动展开祖先，选中项滚入左侧可见区域，不滚动整页到分类树底部 |
| 搜索提交/清空/翻页 | 回车或提交按钮进入搜索路由；查询/分类改变归页1；清空返回首页或当前分类；翻页只取当前页 |
| 点击搜索结果 | 优先定位headingId，否则文章顶部；返回恢复q/分类/页码/列表位置 |
| 点击大纲章节 | 更新hash并滚到标题，预留头部偏移；减少动效时直接定位 |
| 滚动正文 | 用IntersectionObserver跟踪实际章节，更新大纲高亮，不每次push浏览器历史、不触发跳回 |
| 点击文章内帮助链接 | 当前域内导航；失效目标显示明确不可用，不能请求另一端寻找同名文章 |
| 复制文章/章节链接 | 使用当前origin及相对帮助路由；复制后轻量成功反馈，不包含鉴权凭据 |
| 浏览器前后退 | 恢复同身份下列表/文章位置；首次直达hash优先，未存位置从顶部开始 |
| 点击前往功能/返回管理台 | 只用当前origin及已授权菜单生成的目标，离开后恢复业务布局与原主题偏好 |

滚动容器由阅读壳统一指定，列表位置恢复和章节观察使用同一容器。图片加载保留比例，章节初次定位在正文布局完成后执行，图片尺寸到位不导致明显漂移；用户已经手动滚动后不反复强制重定位。

搜索不提供跨域联想；本期搜索材料随本域前端分发；首期不存搜索历史，也不与原顶栏菜单搜索合并。列表恢复仅当前身份会话内存有效，重新登录/换组织不恢复旧内容。

## 4. 配图规范与预览

已交付的辅助图和后续实操截图要求见 [CONTENT.md](./CONTENT.md)。文字无法清楚说明入口、表单、选择范围、多步确认、结果或权限关系时，按相应步骤补图。

- 本系统实际测试界面使用演示数据采集，截图文字、按钮、步骤与目标版本一致；不复制飞书截图做本系统教程，也不生成看似真实的虚构操作界面。
- 每步图片紧跟说明，少量①②③、箭头/框选与图注相互对应；保留必要导航上下文，长流程分图。复杂授权关系可辅以原创示意图。
- alt描述图意，caption解释用户应关注的区域；缩略图不足以辨认细节时可以打开原图。宽高提前占位，加载有骨架，失败保留alt/图注与重试。
- 点击已加载缩略图打开遮罩预览；首次原图加载明确显示进度，失败留在预览提供重试，不悄悄显示低清图冒充原图。
- 预览工具包含关闭、缩小、放大、比例、适应窗口、1:1；范围50%～400%，超过视口时可拖动/滚动查看。滚轮缩放只在预览图区域生效，不劫持文章滚轮。
- 同篇多图显示当前位置与前后按钮，键盘←/→切换；只按需读取所选原图，切图重置为适应窗口。缩略图/原图只从本域显式静态资产表读取。
- Esc、关闭按钮或点击遮罩空白关闭；点击图片/工具不误关闭。关闭恢复触发图片焦点及文章位置。
- 预览打开时锁背景滚动并限制焦点在弹层；关闭恢复焦点。退出、换身份、换版本或文章离开立即销毁预览并清空图片src与旧加载状态，不允许弹层留下旧端图片。

## 5. 状态、键盘与可访问性

- 目录/文章初次加载用结构骨架；搜索仅结果区loading；不得把未完成响应当成“暂无文章”。
- 无结果显示当前关键词及建议缩短词/查看分类；本地内容加载失败显示重试与返回管理台；文章不存在显示当前端不可访问的统一文案，不说明另一端存在该篇。
- 分类按钮aria-expanded、选中文章aria-current；搜索有可访问名称与回车提交；输入组合期间不提交；Tab遍历、焦点态和触屏点击区域可用。
- 大纲有导航语义，活动项不抢键盘焦点；图片可用Enter/Space打开，Esc关闭；弹层按钮有名称，focus trap与焦点恢复生效。
- 截图中的文字不能替代正文步骤，重要结果在正文也有说明；颜色并非唯一状态提示。
