# 需求：飞书式帮助中心

## 场景与页面

1. 租户/平台用户点击顶栏“？”进入当前端帮助首页，通过入门卡片或分类找到说明。
2. 用户输入“导入人员”等用语，查看高亮搜索摘要，打开命中文章/章节，返回时恢复条件、页码和列表位置。
3. 用户从业务页“使用说明”进入相关教程，通过分类树切换文章，通过右侧大纲定位步骤。
4. 用户阅读配图、点击放大并缩放，核对操作；关闭后仍停留在原步骤。
5. 用户点击文章“前往功能”，只能进入当前身份已授权的正式菜单，不因为读过教程获得新权限。
6. 用户退出、切换组织/身份或会话失效时，旧文章、结果及图片立即清理，旧请求不能回填。

## 功能需求

| ID | 要求 |
| --- | --- |
| F01 | 两端现有BizHeaderHelp接入真实入口；顶栏按钮始终进入当前端 `/help`，业务页说明进入对应文章。帮助不需要专属菜单权限，不增加业务侧栏条目。 |
| F02 | 首页有当前端标识、搜索、快速入门、分类、常见问题及近期更新。展示研发编排的数据，不显示假热度/计数，不提供跨端切换器。 |
| F03 | 分类页/文章页使用飞书式左侧分类树、中间列表/正文、右侧章节目录；选中态浅蓝、层级清晰，文章正文适合连续阅读。具体标准见UX。 |
| F04 | 搜索可回车提交、清空、分类过滤及分页；纯文本高亮、明确加载/无结果/失败，不下发或浏览器检索全站索引。浏览器返回恢复条件和位置，URL可安全复制。 |
| F05 | 分类树收展，打开文章自动展开祖先并定位选中项；大纲点击定位、滚动同步高亮，章节深链可刷新；前后篇和相关文章都限定当前域。 |
| F06 | 图片按步骤配图、等比例占位/懒加载，失败可重试。预览支持适应窗口、1:1、50%～400%缩放、同篇前后切图、Esc/按钮关闭、焦点与滚动恢复。 |
| F07 | 读取接口只用宿主固定域、统一请求链与身份纪元，不从query/文章ID推断域。对返回domain/version校验；正文、目录、图注、缩略图和原图都不跨域。 |
| F08 | 使用受限Markdown并净化，禁用raw HTML/脚本/外部图片。所有自定义图片及帮助链接必须出现在已验证的文章元数据/目录中。业务跳转只由已授权菜单匹配canonical viewPath生成。 |
| F09 | 页面状态、Query缓存、章节位置和Blob URL只保留当前身份内存；退出/切换/版本变化清除，中止旧请求，不写localStorage/IndexedDB/service worker。 |
| F10 | 版本变化409只重新获取目录并重试一次；401进入统一登录处理；403/404/503分别有明确界面，不转请求另一端，不把依赖故障当作合法空。 |
| F11 | 浅色视觉以飞书为参照，使用项目品牌/语义Token；支持显式dark偏好、窄屏、键盘、焦点可见与减少动效。图文有alt/图注，目录和预览可通过键盘操作。 |
| F12 | 目标发布版本功能覆盖100%，需要配图的说明必须有真实演示截图/合适示意图，经实操核对；同版文档、截图与界面一起验收。 |

同域帮助对全部有效成员可读，文章标注“谁能操作”和前置条件。强制改密继续走既有受限流程，不能把帮助路由标为公开来绕开守卫。无业务菜单的有效身份仍应能进入帮助页及返回系统空态。

## 验收标准

- [ ] FA01：两宿主顶栏入口、业务页说明、四类帮助路由的直接访问/刷新/深链正常；帮助不依赖业务菜单授权。
- [ ] FA02：按UX的首页/分类/检索/文章/图片预览逐项对照飞书式目标，完成1440、1280、768、375宽度与light/dark截图记录。
- [ ] FA03：分类树、大纲、章节hash、搜索高亮、分页、浏览器前后退和列表位置恢复正确；无反复跳动或主页面横向滚动。
- [ ] FA04：必要配图覆盖清单完整，文字可读、图注/编号匹配实际操作，懒加载与预览切图、缩放、Esc、焦点/位置恢复通过。
- [ ] FA05：同账号两端、双向域不匹配、伪造参数、复制跨端文章链接、原图/缩略图及断链场景均不泄露另一端信息。
- [ ] FA06：退出/切换组织/会话失效清除DOM、Query与图片URL；旧请求晚到不回填；强制改密与无菜单身份行为正确。
- [ ] FA07：HTML/危险链接/异常媒体被拒绝；前端JS、source map和public产物没有文档、搜索索引、平台图片或源文件。
- [ ] FA08：“前往功能”只对当前可导航菜单生成，未授权时给出权限说明，无越权导航或扩权请求。
- [ ] FA09：409最多自动恢复一次，旧后端/缺包/503可重试或返回管理台，错误不冒充空内容；API及CONTENT副本与后端一致。
- [ ] FA10：插件与受影响共享包定向测试、类型检查、边界检查及两管理台构建通过；完整内容与真实BFF联调、关键路径实操及发布回滚验证完成。

本轮仅落规格，所有实现与产品验收项保持未勾选。
