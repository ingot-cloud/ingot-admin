# 前端说明维护与配图

研发直接编辑common或对应宿主src/help中的Markdown、content.ts元数据和assets图片，随该前端版本发布。保持既有42篇稳定ID和29项页面映射；简单增改不需要运行生成器或安装Python。

正文包含用途、前置条件、入口、字段与规则、步骤、结果和常见问题；使用显式h2～h4章节 `{#stable-id}`。禁止原始HTML和远程图片；文章内链接使用help:article-id#heading-id，配图使用help-asset:id，并在文章assets及本域资产表中声明原图/缩略图。

通用说明只含两端一致行为；租户和平台专属说明、截图、目录、关键词分别放本宿主，不能通过共享barrel/glob引入另一端。图片以 `?url&no-inline` 导入，记录alt、图注、尺寸，不在public放两端共享文档资源。

上述为已验收的静态实现。后续平台帮助资料仍在前端维护，发布时转入受保护的静态制品。配图继续保留原图和缩略图两种尺寸。[资源控制规划](./DESIGN.md#8-平台静态资源访问控制规划)
