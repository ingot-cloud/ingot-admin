# 需求与验收

1. 列表仅由 InTable 提供默认正文留白，移除访问防护列表容器重复 padding；工具栏与表体共用左右边界，保留 contained 表体滚动。
2. InTable 表头/表体的横向内边距只计算一层；访问防护列宽容纳完整标题和枚举标签，不能以换行或裁切状态标签规避列宽不足。窄窗口允许表体横向滚动，固定操作列保持可用。
3. 四种可维护列表的详情继续行内直出，删除使用 InTableActions 的 danger 操作进入更多菜单；沿用框架一次确认、精确 delete 权限、成功刷新当前列表、失败保留当前数据。移除详情抽屉的删除入口。
4. 封禁审计仅浏览，保持无删除入口。保留激活才请求、默认预览、编辑/取消和只读行为。

验收覆盖五种列表在宽/常规/窄窗口和明暗主题下的实际留白、表头单行与标签矩形；删除菜单、取消、成功/失败和只读权限，以及既有安全中心交互。共享单元格修复须验证框架组件、其他表格页及两管理台构建。
