# 租户添加成员对话框

> 状态：implementing

## 协作模式

一人全栈

## 背景与动机

现有「添加组织成员」抽屉要求查找或粘贴账号 ID，租户管理员无法按通讯录方式加人。需要改成飞书式对话框：按手机号创建或加入。

## 目标

点击「添加成员」打开对话框，标题为「添加成员」。提交后若新建账号则弹出一次性密码；若已有账号则提示已加入组织。

## 范围

### In Scope

- 对话框字段：姓名、部门、手机号、工作邮箱
- 一次性密码对话框下沉到 admin-common
- 创建 API 对接新契约

### Out of Scope

- 飞书「工作信息」与更多人事字段
- 平台人员创建流程
