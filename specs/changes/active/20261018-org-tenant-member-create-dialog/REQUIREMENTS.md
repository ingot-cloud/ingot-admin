# Requirements

## 用户场景

1. 管理员点击「添加成员」，看到标题为「添加成员」的对话框，而不是「添加组织成员」抽屉。
2. 填写姓名、部门、手机号和可选工作邮箱后点「完成」。
3. 新手机号创建成功后弹出一次性密码；已有账号则提示「该手机号已有账号，已加入组织」。

## 业务规则

1. 字段对齐飞书基础信息：姓名、部门、手机号码、工作邮箱。不出现账号 ID 或登录名查找。
2. 部门默认带上左侧树当前部门，可清空。
3. 手机号输入框前置 `+86`。前端只校验 11 位数字；号段等业务规则由后端判断，规则变化时前端不跟着改。
4. 姓名、邮箱是否可编辑看创建字段上下文。
5. 导入/导出不受影响。

## 边界与非目标

- 不做飞书工作信息、邀请成员、短信发送。
- 平台「创建全局账号」抽屉保持原样，只改密码对话框的公共引用。

## 验收标准

- [ ] 标题为「添加成员」，交互是对话框
- [ ] 无账号 ID / 登录名查找
- [ ] 新建账号弹出一次性密码
- [ ] 已有账号提示加入组织并刷新列表
