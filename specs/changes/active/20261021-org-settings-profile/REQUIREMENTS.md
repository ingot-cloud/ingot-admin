# 需求：组织设置页

## 场景

组织管理员打开组织设置。有更新权限时可以改 Logo 和名称。当前所有者可以转交：先单选一名其他成员，确认后再输入登录密码。取消、关闭、未选人或未填密码都不转交。密码错误时人选保留，所有者不变。

## 验收标准

- 基础信息是浅色横幅：Logo（无图时名称首字）和名称，编辑入口只在有更新权限时出现。
- 更多信息只读：组织编号可复制、当前所有者、手机、邮箱、创建时间、启停状态。空值显示「-」。不展示套餐 ID，没有编辑按钮。
- 基础信息、更多信息和转交各自用圆角边框围住。
- 底部仅当前所有者且具备转交权限时显示红色「转交所有者」和说明，不是解散按钮。
- 成员对话框单选。选中当前所有者不能进入密码步。
- 密码确认是唯一调用转交接口的地方，请求带 `LOGIN_PASSWORD`，`secret` 走字段级 HYBRID。
