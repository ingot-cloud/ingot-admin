# 组织设置页

> 状态：implementing

## 协作模式

一人全栈

## 背景与动机

组织设置仍是一张混着名称和转交的表单，没有 Logo、创建时间和所有者联系方式。转交可以直接提交，没有登录密码。

## 目标

页面按飞书企业信息排成基础信息横幅和只读更多信息。底部提供转交所有者：先单选成员，再在同一次请求里验证登录密码。

## 范围

### In Scope

- 基础信息只编辑 Logo 和名称
- 更多信息只读展示已有字段
- 两步转交，密码与人选一次提交

### Out of Scope

- 企业地址、认证、行业、规模、域名、解散组织
- 单独验密接口
