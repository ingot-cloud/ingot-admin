# 需求：勾选框与树展开规范

## 用户场景

- 管理员在任意表单、表格、树和树选择里看到同一套多选、单选和树展开箭头。
- 浅色和深色主题下，勾选色跟随主题色，箭头跟随次要文字色。

## 验收标准

1. 多选为 16px、圆角 4px。未选是 1px 边框、透明底；选中是主题色底和边框，勾为 Element Plus 原生白色勾。
2. 半选横条用一次 `translate(-50%, -50%)` 居中，不再叠加 `scale` 和 `translateY`。
3. 单选为 16px 圆。选中是主题色边框加圆心，不是方框，也不是整圆填色。
4. 禁用的多选和单选降低不透明度。
5. `el-tree`、`InTree`、`el-tree-select` 的展开箭头为 12px 实心三角，颜色为 `--in-text-color-secondary`。收起朝右，展开朝下。叶子节点占位但不显示箭头。
6. 表格行展开仍使用现有小箭头，不套这套三角。
7. 部门选择、范围选择、表格和成员选择不再本地覆盖勾选尺寸、勾号或树箭头。
8. 编码规范要求业务页使用 `el-checkbox` / `el-radio` 和全局树箭头，不在页面里再画一套。
