# 需求：组织角色与授权工作区

## 场景

组织管理员打开「权限与授权」后，用角色名称找到角色，查看它关联的成员和用户组，并维护权限范围。角色分配和授权管理员仍在相邻 Tab。

## 角色工作区

- 左栏搜索角色名称并分页。每行显示名称和操作菜单。详情在菜单内，与平台端一致。「创建角色」固定在左栏底部，没有创建权限时禁用。
- 平台共享角色在名称旁显示小号主题色「系统角色」标签。这类角色只能查看和分配，菜单里没有删除。
- 右栏标题为当前角色名称，名称下显示角色说明。子页为「成员」「用户组」。
- 成员列：名称、部门、来源数。部门按主部门优先，没有可见部门时显示「-」。用户组列只有名称。不显示分配来源。没有「查看来源」按钮。
- 点击成员名称打开该成员的只读详情，不提供编辑和暂停、移出等操作。点击用户组名称打开只读用户组详情。没有对应读取权限时名称只展示文字。
- 点击成员的来源数打开「有效分配来源」。用户组的来源数只展示数量。来源列：接收对象、授权依据、失效时间。授权依据只写「直接分配」或「授权管理员分配」。来源里可以查看或撤销分配，用户组来源可打开只读用户组详情，不提供权限诊断。
- 组读取范围受限时，右侧说明「组继承来源按当前组读取范围展示」。
- 没有说明时，名称下显示「暂无说明」。

## 创建与详情

- 创建分五步：角色信息、选择权限、设置范围、字段权限、预览。第一步只有名称、说明、分组。
- 字段权限与平台自有角色相同：在资源已声明的字段里配置可见性、可编辑、可筛选。通讯录资源不出现在这一步。
- 预览按应用、资源、字段中文名和权限说明展示。保存后覆盖当前快照，立即生效，不采集版本名。
- 详情默认权限页。身份区固定展示名称、状态、说明；共享角色再标「系统角色」。
- 身份区和权限工具条不随内容滚动，只有权限列表面板溢出时滚动。
- 私有角色可改名称、分组、状态、说明，并可进入权限向导。共享角色不提供这些编辑。
- 权限向导四步：选择权限、设置范围、字段权限、预览。预览通过后才能保存。保存后关联人员自动生效。
- 范围步骤说明：此处确定角色允许使用的范围；管理部门和指定对象在分配角色时选择。
- 预览按应用、资源、操作名称、中文范围和字段中文名展示。

## 相邻 Tab

- 「角色分配」（原「授权记录」）可搜索授权成员或用户组，按接收对象筛选，并设置列。主体显示「成员/用户组 / 名称」。来源不展示委派标识。页头写「管理组织角色、角色分配和授权管理员」。
- 工具栏主按钮为「分配角色」。「权限诊断」只出现在这个 Tab：工具栏为次要按钮，空间不足时收进「更多」；行内操作为修改、诊断（仅成员）、撤销。角色 Tab 的工具栏和成员行都不提供诊断。
- 「授权管理员」搜索管理员名称。无名称时显示「未命名管理员」。

## 分配角色

与平台「分配角色」使用同样的四步全屏向导，左侧步骤栏，差别只在没有角色版本。

1. 授权依据与接收对象：有直接分配资格时显示「直接分配」；否则选择本人的授权委派，并显示其可分配角色、人群和最长期限。成员与用户组可同时多选。切换授权依据会清空接收对象和角色。
2. 选择角色与设置有效期：多选当前角色，不选版本。所选角色共用有效期。委派来源下必须设置失效时间，且不超过来源期限与单次最长时长。
3. 设置范围：按「角色 × 范围参数」逐项填写管理部门或指定对象，显示需配置、已配置、待配置数量，可只看未配置。有待配置项时不能进入下一步。角色无参数时提示无需配置。
4. 预览与保存：展示授权依据、接收对象、角色、分配条数与有效期，先「预览效果」，通过后才出现「分配角色」。

- 新建按「接收对象 × 角色」组成一批提交，整批原子成功或失败。
- 修改只针对一条记录：接收对象和角色只读，可改范围和有效期，保存按钮为「保存」。
- 保存后刷新会话权限，列表与角色工作区同步刷新。未保存关闭需确认。

## 权限诊断

- 用于排查「某成员为什么能 / 不能做某事」，只读，不模拟执行。
- 依次选择成员、应用、操作，目标对象可选；不再手填任何 ID。应用变化清空操作和目标，操作变化清空目标。
- 候选只包含诊断时会被接受的对象：可见成员、已开通应用、该应用已启用操作、操作资源下可见的对象。资源未接入对象查询时提示留空只诊断操作。
- 从行内「诊断」打开时成员已锁定为该记录的成员。

## 验收

- 页面任何位置都不出现角色编码、版本号、版本筛选或升级。
- 成员和用户组来自角色工作区接口，不按 ID 回查角色列表。
- 创建成功后新角色出现在左栏，且请求体中的编码不回显。
- 共享角色详情没有编辑入口。
- 页面不再出现「授权记录」「分配授权」文案。
- 一次为 2 名成员和 1 个用户组分配 2 个角色，预览和保存提交 6 条分配。
- 委派来源下只能选该委派允许的角色和人群，范围候选不超出委派上限。
- 诊断抽屉没有手填 ID 的输入框。
