# 需求与验收

1. 整页配置表单正文最大宽度默认 840px，在主工作区内横向居中；工作区可用宽度不足时收缩，保留 Token 内边距，任何可见按钮、输入与长文本均在容器内。
2. 页头、页级 Tab 保持工作区宽度。预览和编辑共享正文宽度、字段布局和操作按钮对齐边界。常规字段默认两列，短选项可三列，长文本与标签字段独占一行；窄屏自动收为一列。
3. 凭证四个 Tab 接入；账号保护拆为「B 端锁定策略」「C 端锁定策略」两个页级 Tab，默认 B 端；各自编辑保存，激活才读取对应用户类型，切换保留已访问 Tab 的编辑草稿；访问防护仅登录失败保护、违规升级配置表单接入。列表与详情抽屉不强制限宽，混合页面由实际内容类型决定布局。
4. 新增共享正文容器和可覆盖宽度 Token，开发文档与仓库门禁说明后续整页配置表单的默认用法。容器只负责布局，不承载授权、校验、请求或保存。
5. 保留激活才请求、默认预览、取消恢复、失败留草稿、数字字符串兼容、精确权限与现有业务约束。

验收：宽屏/常规屏/窄屏、侧栏收起、明暗主题下检查实际正文宽度与左右留白；预览/编辑对齐一致；账号保护两 Tab 的按需读取、草稿隔离与独立保存保持；登录失败嵌套 Tab 请求保持；混合页面切回列表仍填充工作区。完成相关组件/插件测试、类型、只读 lint、主题 Token 协议、依赖边界、两后台构建及隔离接口浏览器回归。
