# 组织用户组左右栏

> 状态：implementing

## 协作模式

一人全栈

## 背景与动机

组织「用户组」仍是整表 + 编辑抽屉，平台人员「组」Tab 已是左组右人。组织组还支持部门来源，部门加人后有效成员会自动增加，但旧页看不到展开结果。

## 目标

`/org/iam/groups` 改为左组右人。右侧展示有效成员（含部门展开）。创建和编辑走分步向导，并可设置部门范围；详情仍是抽屉。

## 范围

### In Scope

- 左组列表、右有效成员表
- 工作区直接添加/移出（只改 `selection.members`，保留部门来源，不预览）
- 创建/编辑走分步向导，可设成员与部门；编辑须预览。详情抽屉只读，编辑从抽屉进入向导
- 来源列与仅部门来源不可移出

### Out of Scope

- 平台人员组 Tab
- 改直接成员接口语义
- 提前改 `specs/current/`
