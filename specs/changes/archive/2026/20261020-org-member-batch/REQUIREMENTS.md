# 需求：成员批量变更部门与导入导出页

## 场景与页面

### 场景 1：批量变更部门

- **角色**：具备 `iam-tenant:member:departments` 的租户管理员
- **入口**：成员表工具栏「批量变更部门」
- **步骤**：未选可操作成员时按钮禁用（「请先选择成员」或「组织拥有者不能被暂停、移出或变更部门」）。点击后打开「变更部门」对话框，勾选并排序新部门，第一项为主部门。第一层确定不提交，再弹出「确认变更部门？」。确认后逐人覆盖任职。
- **预期结果**：全部成功关闭两层并刷新，提示人数。部分失败提示成功和失败人数，有成功则刷新。取消确认回到选择层且勾选保留。

### 场景 2：批量导入或导出

- **角色**：具备创建或导出权限的租户管理员
- **入口**：成员表工具栏「批量导入/导出」
- **步骤**：进入新页面。分段选择「导入新成员」或「导出并修改成员信息」（无权限的选项不出现）。下载/导出后在虚线区选择或拖入 xlsx，右下角「导入」。导出先打开范围对话框，默认「全部」；选「部分成员」后在同一对话框内选择成员或部门，部门表示该部门及其下级中的成员。第二张卡右侧打开「你的导入历史」。
- **预期结果**：返回或取消回到成员列表。导入后展示成功数、失败行，可下载错误报告；创建导入可一次性下载初始密码。

### 页面结构

- 变更部门：约 894×732 对话框，左右分栏 846×522，搜索+部门树 / 已选列表。确认框 420，无关闭按钮，浅底「部门变化」流式标签。
- 导入导出页：面包屑在白底外；白底页头返回+标题；`InFormContent` 居中步骤区；两张浅底步骤卡；底部取消与导入。

## 验收标准

- [ ] 未选可操作成员时变更部门禁用原因与现网一致
- [ ] 选择层确定不提交；确认层确定才逐人 PUT
- [ ] 确认框展示本次可提交成员与新部门，组织拥有者已排除
- [ ] 导入导出进入新页面，侧栏不新增菜单，部门页仍提示即将开放
- [ ] 无权限的分段选项不出现；未选文件时导入禁用
- [ ] 导出范围对话框默认全部；部分成员在同一对话框内选择，可选部门，取消不导出
- [ ] 历史只看当前操作者最近 10 条

## ADDED

### REQ-A001：两层变更部门对话框

**验收标准：**

- [ ] 未选部门时确定禁用；取消或关闭丢弃选择
- [ ] 右栏未选时空白，勾选后才出现「已选：N 个部门」与清空
- [ ] 已暂停可变更，已移出与拥有者不在提交名单

### REQ-A002：居中导入导出页

**验收标准：**

- [ ] 页头通栏不进限宽容器；步骤区约 824 居中
- [ ] 创建与更新共用第二张卡、拖拽区和底部按钮
- [ ] 只接受 xlsx；结果含成功数、失败原因和错误报告
