# 设计：统一登录错误提示

- 两个宿主共用 `plugins/auth/src/pages/login`。由 `useOps` 统一上报登录错误，通过共享 `AuthSession` 注入的错误提示调用 `admin-core` 的 `Message.error`。认证请求继续使用静默网络反馈，登录页发起的会话初始化及改密状态查询也使用同一反馈方式，避免重复提示。
- `IndexPage.vue` 删除卡片内错误文本；需要重新确认时在当前内容下方保留操作按钮。保留现有的事务恢复和表单逻辑。
- 兼容性：两个宿主已有的共享适配器同时实现错误提示。路由、后端接口、数据、部署与登录配色配置无需迁移。

## 宪章符合性

宿主通过已有共享契约提供反馈；插件保留页面与操作编排，不依赖宿主内部实现或其他插件。验证复用同源登录的浏览器场景，覆盖双端错误消息和恢复入口。
