# 需求：详情查看/编辑标准

## 场景与页面

### 场景 1：查看成员详情

- **角色**：组织管理员。
- **入口**：通讯录成员列表行「详情」或头像。
- **步骤**：打开右侧抽屉。
- **预期结果**：标题为「成员详情」；展示头像、姓名、账号状态和「更多操作」；默认只读字段；底部为「编辑基本信息」。

### 场景 2：编辑基本信息

- **角色**：组织管理员。
- **入口**：成员详情抽屉底部「编辑基本信息」。
- **步骤**：修改字段后保存或取消。
- **预期结果**：字段变为输入框；底部为「取消」「保存」；取消回到查看态并丢弃未保存修改；保存成功后回到查看态并刷新列表。

### 场景 3：编辑中离开

- **角色**：组织管理员。
- **入口**：编辑态下关闭抽屉或切换 Tab。
- **步骤**：点击关闭 / Esc / 其它 Tab。
- **预期结果**：弹出「确定退出当前编辑？」；说明「退出后，修改的内容不会被保存」；取消留下，确定丢弃并继续。

### 场景 4：添加成员

- **角色**：组织管理员。
- **入口**：工具栏「添加成员」。
- **步骤**：填写并提交。
- **预期结果**：仍直接打开创建表单，不进入查看态。

### 页面结构

```text
InDetailDrawer
├── Header：成员详情
├── Identity：头像 + 姓名 + 状态 + 更多操作（暂停/恢复、删除）
├── InBizTabs：基本信息
├── Body：只读描述列表 或 编辑表单
└── Footer：编辑基本信息 或 取消/保存
```

## ADDED

### REQ-A001：页内 Tab 墨条

系统 SHALL 提供飞书式页内 Tab：16px 字号、默认主文字色、选中主色、3px 活动条跟随选中项。

**验收标准：**

- [ ] 默认色使用 `--in-text-color`，选中色使用 `--in-color-primary`。
- [ ] 活动条可见高度 3px，宽度与选中文案同宽，顶部圆角，半条压在底部分隔线上；以 `left`/`width` 定位，动效 `0.3s cubic-bezier(.34,.69,.1,1)`。
- [ ] `before-change` 返回 false 时不切换。
- [ ] 遵守 `prefers-reduced-motion`。

### REQ-A002：详情抽屉标准壳层

系统 SHALL 在 `@ingot/admin-core` 提供查看/编辑详情抽屉标准。

**验收标准：**

- [ ] 查看态底部只出「编辑{当前分组}」主按钮；编辑态出取消与保存。
- [ ] 编辑态关闭或切 Tab 必须确认；文案为「确定退出当前编辑？」；走公共确认框且 `showClose: false`。
- [ ] identity 与 Tab 钉住，仅字段区滚动。
- [ ] 普通 `InDrawer` 默认滚动行为不变。

### REQ-A003：只读描述与身份区

系统 SHALL 提供上标签下值的只读列表和大号身份区。

**验收标准：**

- [ ] 空值显示 `-`，不用 disabled 输入框冒充只读。
- [ ] 身份区为大号头像、姓名、状态槽和右侧更多操作槽。
- [ ] 编辑态头像在身份区原地更换：悬停出现半透明遮罩和相机图标，不在表单里再出头像字段。

### REQ-A005：公共确认框

系统 SHALL 提供统一的公共确认框，供命令式 `Confirm` 与声明式 `InDialog` 共用同一视觉。

**验收标准：**

- [ ] 对话框在视口水平、垂直居中。
- [ ] 内容可以是文案或自定义 VNode / 默认插槽。
- [ ] 右上角关闭按钮由 `showClose` 控制，默认显示；离开编辑确认关闭该按钮。
- [ ] 标题左侧图标可传入组件、VNode，或传 `false` / 不提供 `#icon` 以隐藏；`Confirm` 默认按语气显示填充图标。
- [ ] 白底、8px 圆角、标题色 `--in-text-color`。

### REQ-A006：操作下拉菜单

系统 SHALL 提供统一的操作下拉：无箭头、无条目分割线。

**验收标准：**

- [ ] 容器 `1px` `--in-border-color`、`6px` `--in-radius-control`、`--in-shadow-overlay`、文字 `--in-text-color`。
- [ ] 不显示 Popper 箭头。
- [ ] 成员详情「更多操作」右对齐展开，条目之间无分割线。

### REQ-A004：成员详情试点

通讯录成员详情 SHALL 接入该标准；添加成员仍为创建表单。

**验收标准：**

- [ ] 详情默认只读；查看态与编辑态字段顺序一致：姓名、用户名、手机号、email、部门。
- [ ] 头像只在身份区展示；编辑态悬停身份区头像上传，表单不再单独出现头像项。
- [ ] 更多操作仅暂停/恢复与删除；成功后刷新列表，删除后关闭抽屉。
- [ ] 不出现上一个/下一个或平台没有的飞书字段。
