# 租户端直接切换组织需求

## 已批准范围

用户完成 Plan 讨论并于 2026-11-12 明确要求实施修订方案；本次按已确认方案施工，不消费其他 inbox。

- 独立 /auth/organizations 页面；当前组织单独展示，其他有效组织搜索分页。
- 当前 token 必须校验签名、issuer、exp/nbf、aud、在线 sid、账号/租户/客户端一致性；权威状态不可用返回 503，不允许 JWT-only 降级签发。
- 不信任客户端账号、成员、域或客户端；查询、创建、提交都重验账号状态及当前 token。
- switchableTotal 排除当前组织且不受搜索影响；零候选提示并 replace 返回当前组织，不签发/撤销/替换会话；搜索空留页。
- 来源成员失效但账号与 token 有效时可切其他有效组织；无其他组织进入稳定无权限页。
- 新 sid、新 token、新 BFF 会话；期限不超来源 BFF 与 Auth 凭据链的较早截止；不扣密码登录宽限次数。
- CAS 替换、幂等签发、丢响应恢复、可靠撤销；退出和新登录后不能恢复旧结果。
- 同源租户标签全部清旧上下文后去目标工作台，依次回退首个可访问菜单、稳定空态；平台不提供切换。
- In-Bff-Context-Version 阻止旧页借新 Cookie 发送请求，不能重放旧写操作。
