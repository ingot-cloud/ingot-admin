# candidate10 账号安全变更故障复验

2026-11-14：5类业务变更×7个故障点，共35个独立场景通过；另5组真实浏览器旧证明验证通过。未提交，发布仍受性能等剩余门禁阻断。

- 类型：改密、重置密码、锁定、禁用、解锁。
- 故障点：阻断前后、IAM业务提交前后、结果确认后、Auth解除阻断前后。真实行锁、断网、丢回包和SIGKILL分别建立故障点；未知结果保持超过120秒硬截止后仍不能自动解除阻断。
- 业务提交前崩溃最终ROLLED_BACK，迟到执行者受租约/fence拒绝；业务已提交则IAM与Auth最终COMMITTED。outbox最终DONE、无残留BLOCKED；解除阻断后重启不重复推进安全代次。
- 旧RT及派生凭据证明在阻断后失效；业务回滚或解锁也不复活。正式AT撤销保留既有管理域/租户范围：自助改密撤销当前租户、平台管理操作撤销平台范围；未宣称跨域所有正式AT均被撤销。
- 浏览器为每类变更分别建立两套旧预授权与待提交组织切换：BLOCKED期间及终态后均拒绝，且均无正式Cookie回包；解锁也不恢复锁定前旧证明。

35项按(type, point)唯一键核对完整，来自多个独立批次，不宣称一次连续35项运行。先前脚本失败原样保留：结果拦截应仅持有终态而非PREPARED；outbox观察锁只锁该行；禁用/锁定不应错误断言既有account_profile.version递增，安全依据是独立scopeEpoch/fence和实际业务字段。修正测试装置后重验，未修改产品行为。
