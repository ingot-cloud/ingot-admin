# 需求：已移出成员重新加入

## 场景与页面

### 场景 1：添加成员命中已移出

- **角色**：具备 `iam-tenant:member:create`
- **入口**：成员页 → 添加成员
- **步骤**：填写已移出成员的手机号与新姓名后提交
- **预期结果**：提示「该成员已重新加入组织，原有角色和用户组已清除」，列表刷新为在职

### 场景 2：已移出列表重新加入

- **角色**：具备 `iam-tenant:member:create`
- **入口**：成员页筛选已移出 → 行操作或详情
- **步骤**：打开「重新加入」对话框，可改姓名、手机号、邮箱、部门后提交
- **预期结果**：旧授权关系清除，成员回到在职列表

## 功能需求

### ADDED

- 已移出行显示「重新加入」，权限为创建成员
- `MemberRejoinDialog` 预填原资料，提示旧角色和用户组会被清除
- 添加成员成功且 `rejoined=true` 时使用重新加入提示，不弹出初始密码
