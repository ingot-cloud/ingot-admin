# 需求：部门批量导入导出页

## 场景与页面

- **角色**：具备部门创建或导出权限的租户管理员
- **入口**：部门表工具栏「批量导入/导出」
- **步骤**：进入隐藏页。分段「导入新部门」或「导出并修改部门信息」（无权限的选项不出现）。创建模式下载空白模板；更新模式打开范围对话框后导出到「我的下载」。第二张卡上传 xlsx，右侧打开「你的导入历史」。
- **预期结果**：返回或取消回到 `/org/iam/departments`。导入后展示成功和失败部门数，可下载错误报告。

## 页面结构

- 页头通栏返回 + 标题「批量导入或导出部门」
- `InFormContent` 824 居中；两张浅底步骤卡；210 虚线拖拽区；底部 80×32「取消」「导入」
- 范围对话框标题「编辑管理范围」。默认「全部」420px；「部分部门」840px，同框勾选部门树。勾选表示该部门及其下级，只提交部门 ID。

## 验收标准

- [ ] 工具栏在具备创建或导出权限时出现，点击进入隐藏路由，侧栏不新增菜单
- [ ] 无权限的分段不出现；未选文件时导入禁用；切换分段清空文件
- [ ] 只接受 xlsx
- [ ] 导出范围默认全部；部分未选时确定禁用；空范围提示「所选范围内没有可导出的部门」
- [ ] 导出提交即返回并引导「我的下载」
- [ ] 导入页内轮询；结果「成功 X 个部门，失败 Y 个部门」；历史状态用枚举中文标签
