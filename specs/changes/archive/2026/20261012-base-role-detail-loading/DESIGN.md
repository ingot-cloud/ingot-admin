# 角色详情加载设计与兼容性

- 提取详情加载 composable，元数据、权限、统计、历史和任务独立 loading、错误、重试及 guard；主骨架仅等元数据。
- 最新版本来自 grants 摘要，取消首屏 `revisions?page=1&pageSize=1`。编辑时并行读取该固定版本详情/授权，保留历史来源、字段权限、乐观锁及应用流程。
- 历史/任务首次进入加载，返回已加载 tab 不重复请求且保留页码；变更后标 dirty，只立即刷新当前激活且受影响的列表。任务详情已有 RUNNING 轮询不变。
- 基本资料保存只刷新详情；版本信息保存刷新摘要并失效历史/任务/分布；权限发布刷新详情/授权并失效历史；应用成功刷新分布并失效任务。消除保存版本信息时重复历史请求。
- 新角色/关闭使所有 guard 失效并清理数据；同角色刷新保留角色类型，避免销毁已显示的应用向导。
- 不新增缓存/聚合接口，不改变统计治理边界，不展开平台人员或组织角色公共详情的其他加载逻辑。

最终实现遵循已批准设计，没有设计偏离。
