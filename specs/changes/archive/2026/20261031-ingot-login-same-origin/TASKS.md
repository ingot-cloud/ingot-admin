# 前端任务与门禁

> 状态：completed；已获用户批准并实施，本地验收通过；目标环境余项独立移交，见 VALIDATION.md。

## 决策

- 双管理宿主各有/login/，双域名或纯IP双端口；没有四域兼容分支。
- auth插件承载页面，App注入admin-core公共能力，auth-core持有无页面契约；不违反依赖方向。
- 打开页不建事务；点击后准备；COMPLETED直接Cookie；GET本次结果+一次resume异常恢复。
- 同origin有效绑定复用；同origin身份纪元及通知清旧UI；另一应用不受影响。
- 外观成果复用；退役独立auth App，不保留复制的网络/验证码逻辑。
- 前端API副本由后端同步，不自行新增接口；后端draft变化必须先同步再实施。
