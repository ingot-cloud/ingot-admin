# 需求：同源登录页面与恢复

> 状态：completed；已获用户批准并实施，本地证据与真实环境待验项见 VALIDATION.md。

## 场景与页面

- 平台：apps/admin-platform 的 /login/ 与管理页面同源，配置 PLATFORM/platform-admin，不展示组织候选。
- 租户：apps/admin 的 /login/ 与管理页面同源，配置 TENANT/tenant-admin；单组织自动进入、多组织当前页选择。
- 有域名用两个 origin，纯 IP 用两个 HTTPS 端口；页面及 API 路径相同。
- 登录页复用现有品牌、表单、明暗策略和响应式，无管理菜单/页头/业务装配。无表格，不创建空 table.ts。
- 账号/密码输入、忘记密码提示、提交 loading、挑战弹层、组织列表与返回、网络错误和恢复反馈完整可操作。

## ADDED

### R01 稳定入口

直接打开/收藏 /login/ 显示表单，不要求 tx，不先跳 /auth/start，不预先创建服务器事务或验证码。
页面停留一小时、隔天、休眠恢复后都能点击提交；准备在后台完成，不重载页面。
旧 tx/ticket 不成为认证依据；旧页面兼容处理见 R08。

### R02 点击时准备

一次点击合并为一条 CSRF→创建事务→提交凭证链路。用户名、密码必填，loading 禁重复点击，业务/网络失败结束loading并保留可重试表单。
只在未认证准备阶段原地修复一次过期绑定/CSRF；不能无限自动重试、循环滑块、后台心跳或静默重放密码。

### R03 明确成功与不确定状态

响应 SELECT_TENANT 切组织页并清密码；COMPLETED 才进入成功确认。
网络结果不明、409 busy 先查本次事务，最多15秒；COMPLETED 以本次 sessionEstablished 确认，必要时仅一次受限 resume。
已有旧账号 me 成功不代表新登录成功。恢复失败停留当前页提示重新认证；密码不写localStorage/sessionStorage/URL/日志。
COMPLETED 后校验应用与实际 Cookie，清旧身份缓存，再 bootstrap；不能仅收到业务成功码就显示旧菜单。
成功链路中的身份纪元、权限版本和菜单更新须保持当前登录页实例；bootstrap 较慢时也不得反复挂载/恢复同一完成事务。正常完成只读本次事务、me、bootstrap 各一次，并保留原始受限返回路径；业务缓存仍在切换身份时清理。

### R04 多标签页与身份切换

同origin新标签页不无条件轮换绑定。事务各自独立；仅保留不透明 transactionId 作为本标签恢复线索，服务端仍验证绑定。
切换账号或组织是明确认证操作，普通打开登录页不自动替换身份。发布同origin身份失效通知，其他页清旧查询/菜单/详情/表单，迟到响应不得回填。
平台和租户不同origin，通知与退出互不影响；服务端最终代次校验不能由前端纪元替代。
重验完成前暂停受保护页面挂载，包含受限改密路由。旧身份的成功和401响应均不得影响新身份；旧请求的异步准备与加密/挑战重试不得跨身份发送。显式退出、并发401和跨标签退出只清理/导航一次；接收退出事件不查询已退出身份。

### R05 失败分类与受限账号

密码错误、锁定、无身份按原文案；503显示暂不可用，不作为过期、不清旧身份、不跳另一入口。
初始/重置密码强制改密保持受限门禁，先获取必要状态，不提前装配业务菜单/权限。无菜单显示已登录空态，不重返登录循环。
组织候选变更或认证期限过期，留当前登录页重新认证；不能用新绑定承接旧认证结果。

### R06 安全与部署

仅同源相对 /api，保留HYBRID、防重放和全局412；同一宿主只能一个ChallengeHost/solver。
纯IP两个端口不混Cookie，前端不读HttpOnly Cookie或自行设置Domain；服务器负责隔离。
登录页进入管理origin信任边界，不引入第三方脚本/外部图片依赖；登录与后台主题切换不污染持久偏好。

## MODIFIED

### R07 当前密码登录行为与外观

保留现有“点击先提交，网关需要时全局滑块”、语义表单、键盘提交、默认浅色及auto/dark/light配置、品牌与宽窄屏反馈。
运行宿主由两个独立auth App迁到两个管理App，配置随宿主迁移，离开登录路由恢复管理台主题策略。

### R08 入口、退出与深链

业务401只进入本应用 /login/，按既有规则保存本origin规范化相对深链；不得接受绝对redirect_uri。
/auth/start、/auth/complete、/oauth2/challenge旧地址在当前origin去掉tx/ticket等旧参数并replace到/login/，不消费ticket、不跨域。
正常无效会话进入表单；已有会话普通访问登录可通过me/bootstrap进入本应用，显式退出/切账号标识必须强制显示表单，不能弹回旧账号。
显式退出不保存刚退出页面为returnTo，成功只清当前origin本应用状态；继续保留后端退出兜底语义。
