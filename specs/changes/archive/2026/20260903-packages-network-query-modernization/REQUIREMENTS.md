# 需求：网络请求与服务端状态现代化

## 场景与行为

### 场景 1：管理端读取和复用服务端数据

- **角色**：管理后台用户。
- **入口**：admin 各业务插件页面。
- **步骤**：进入列表或详情、切换分页、返回已访问页面、手动刷新。
- **预期结果**：同一 Query Key 的并发请求被合并；新鲜缓存可复用；过期数据按策略刷新；首次加载与后台刷新状态可区分。

### 场景 2：管理端执行写操作

- **角色**：具备相应权限的管理后台用户。
- **入口**：创建、修改、删除、状态切换、会话下线等操作。
- **步骤**：确认操作并提交 Mutation。
- **预期结果**：写请求不自动重试；成功后只失效相关列表和详情；失败只提示一次且不错误刷新缓存。

### 场景 3：快速切换查询条件或离开页面

- **角色**：管理后台用户。
- **入口**：条件查询、分页、Tab 或路由切换。
- **步骤**：在前一次请求完成前提交新条件或卸载查询。
- **预期结果**：Query 的 AbortSignal 传入 Axios；过期响应不能覆盖新结果；主动取消不显示错误提示。

### 场景 4：公网通过 HTTP/2 访问

- **角色**：部署和运维人员。
- **入口**：公网 admin/login HTTPS 域名。
- **步骤**：通过浏览器或 curl 访问静态资源和 `/api/`。
- **预期结果**：浏览器到 TLS 终止代理协商 `h2`；应用容器保持明文 3000；容器到 gateway 复用 HTTP/1.1 keepalive 连接。

### 场景 5：HTTP/1.1 客户环境兼容

- **角色**：只能使用 HTTP/1.1 的客户环境用户。
- **入口**：任意管理页面。
- **步骤**：页面产生超过浏览器可即时发送数量的独立请求。
- **预期结果**：浏览器排队后请求仍全部正确完成；前端不因协议检测或全局信号量产生死锁、饥饿或错误超时。

## 验收标准

- [x] admin 与 auth 复用同一套无 Vue/UI 依赖的 HTTP Client 基础能力，应用差异由适配器注入。
- [x] API 文件继续导出具名 `XxxAPI` 函数，并显式返回 `Promise<R<T>>`。
- [x] Query 缓存仅保存业务 `data`，不保存 Axios config、headers 等传输元数据。
- [x] Query Key 完整包含影响响应的非敏感、可序列化参数，不包含 Token、密码、手机号等敏感值。
- [x] 相同 Query Key 并发只产生一次请求，变更筛选或分页时旧请求可取消。
- [x] Mutation 默认不重试，成功后精确失效相关缓存，错误提示最多一次。
- [x] 普通、引用和高实时数据具有明确且可覆盖的 staleTime；缓存只驻留内存。
- [x] 登出先取消进行中的 Query，再清空所有缓存，不泄漏上一用户数据。
- [x] NProgress 在并发请求下不会提前结束；后台 Query 默认不触发全局进度条。
- [x] 401、业务失败、412 挑战、信封加解密、kid 轮换行为与现状等价。
- [ ] 外层 HTTPS 入口的 `/` 与 `/api/` 均协商 HTTP/2（仓库外运维项）。
- [x] 项目容器 Nginx 到 gateway 使用 HTTP/1.1 upstream keepalive，并保持现有 `/api/` 路径改写语义。
- [x] admin、auth 与 create-app 模板的 Docker/Nginx 配置同步且 Dockerfile 含 `nginx -t`。
- [x] 不实现全局 HTTP/1.1 六并发限制；仅允许明确批处理业务在自己的 Hook 内局部限流。
- [x] 平台应用管理和在线会话管理两个试点通过后，才开始逐域迁移。
- [x] 全量 `pnpm check` 通过；Docker 镜像构建与公网协议检查由部署流水线 / 运维环境执行。

## ADDED

### REQ-A001：HTTP Client 分层

共享 HTTP Client SHALL 只承担传输、响应归一化、错误分类、取消和可组合拦截器；不得依赖 Vue、Pinia 或 Element Plus。

### REQ-A002：TanStack Query 职责

TanStack Query SHALL 管理 admin 的服务端读取状态、缓存、去重、取消、重试和 Mutation 失效；不得替代 Axios、安全协议或客户端状态 Store。

### REQ-A003：API 导出风格

业务 API SHALL 保持具名函数导出；不得为了命名空间外观改成无状态的 API 单例对象。

### REQ-A004：协议边界

HTTP/2 SHALL 在浏览器实际连接的 TLS 终止节点启用；应用容器 `proxy_http_version 1.1` SHALL 只解释为内网上游协议设置。

### REQ-A005：并发治理

系统 SHALL 通过 HTTP/2、多路复用、Query 去重/缓存/取消、懒加载和后端聚合治理并发；不得在全局请求模块硬编码浏览器连接数。

### REQ-A006：迁移兼容

Query 接入 SHALL 先增量提供新能力，旧 `usePaging/transformPageAPI/useConfirm*` 在调用清零前保持可用并标记废弃。
