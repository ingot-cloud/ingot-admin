# 需求：在线会话与并发策略

> 无既有 `current/` 规格，本次为页面改造。接口字段见 [API.md](./API.md)。

## 场景与页面

### 场景 1：查询在线会话并强制下线

- **角色**：平台管理员（菜单 `platform:security:onlinetoken`）
- **入口**：安全中心 / 在线用户 →「在线会话」Tab
- **步骤**：选择客户端或填写用户 ID → 搜索 → 对某行按 sid 下线，或下线该用户全部会话
- **预期结果**：列表一行一个会话；下线成功后刷新；按 sid 已不在线时提示并刷新；按用户下线提示撤销数量

### 场景 2：查看会话详情

- **角色**：平台管理员
- **入口**：会话行「详情」
- **步骤**：打开抽屉查看 sid / jti / UA 等完整字段
- **预期结果**：会话已不存在时提示「会话已不存在」并刷新列表

### 场景 3：维护并发策略

- **角色**：平台管理员（写操作需 `platform:security:session:policy:update` 或超级管理员）
- **入口**：同页「并发策略」Tab
- **步骤**：查看策略列表；新增/编辑（scope 联动 clientId / userType）；GLOBAL 不可删除
- **预期结果**：保存后提示下次登录生效；已在线会话不受影响；`maxSessions=0` 展示为「不限制」

### 页面结构

- 路由不变：`/platform/security/onlinetoken`
- Tab：在线会话 | 并发策略
- 会话筛选：组织、客户端（或手填 clientId）、用户 ID、登录 IP
- 会话表格：扁平列表；操作含详情、按 sid 下线、按用户下线
- 策略列表：无分页；GLOBAL 置顶且禁用删除；编辑抽屉全量提交

## 验收标准

- [x] 未选 clientId 且未填 userId 时不发列表请求，并提示
- [x] 按 IP 过滤时必须同时有 clientId
- [x] 下线入参为 sid，不再使用 jti
- [x] 时间字段按本地时区展示；`lastAccessAt` 文案为「最近凭据活动」
- [x] 名称为空时用 username / userId、tenantId 兜底，不禁用下线
- [x] 仅按 Client 查询时有「按在线用户翻页」提示
- [x] 并发策略 GLOBAL 不可删；保存提示「下次登录生效」
- [x] 前端不传 Bearer Token
