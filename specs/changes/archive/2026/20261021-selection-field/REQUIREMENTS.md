# Requirements

## R1 基础标签

- 结构为「头像 + 名字 + 删除」，头像与删除可省略。
- 无图片时头像为主题色圆形，前景为名字最后一位，文字不溢出。
- 背景为圆角矩形，默认 `#e1eaff`（深色主题有对应值），可通过属性覆盖。
- 有头像时圆角与头像圆形同心（胶囊形）；无头像时圆角较小。
- 名字、头像可用插槽替换；名字后可插入附加内容（如「含下级」）。
- 点击删除、附加内容不触发外层录入框点击。

## R2 录入框

- 外观对齐输入框，右侧默认 `ep:edit` 图标，可替换或隐藏。
- 点击或按 Enter / Space 打开业务选择器；disabled 时不响应、不显示删除。
- 支持换行与单行两种布局，单行或指定上限时显示 `+N`；`+N` 可基于服务端总数。
- 无选中时显示占位文案。

## R3 迁移

- 成员选择、用户组向导成员、部门选择（含用户组部门范围）、部门负责人、授权接收人、选项标签字段、分页 chip 选择、委派候选、授权角色、平台成员角色均使用新组件回显。
- 业务数据、事件与对话框行为不变。

## 验收标准

- [ ] 上述录入框在浅色、深色主题下外观一致
- [ ] 删除、附加交互不会误开选择器
- [ ] 相关单测与类型检查通过
