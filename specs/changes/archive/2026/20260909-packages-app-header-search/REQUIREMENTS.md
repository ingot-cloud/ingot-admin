# 需求：顶栏菜单搜索（本地路由第一版）

> 独立于顶栏五区配置变更。无后端接口。

## 场景与页面

### 场景 1：按菜单名跳转

- **角色**：已登录、有侧栏菜单权限的管理台用户。
- **入口**：默认顶栏搜索区（`settings.showSearch` 开启时）。
- **步骤**：聚焦或点击搜索框 → 输入菜单名 → 用鼠标或 ↑↓ / Enter 选择一条 → 进入对应页面。
- **预期结果**：面板关闭；路由跳到该菜单 `path`；当前非空关键词写入搜索历史。

### 场景 2：搜索历史

- **角色**：同一浏览器上曾搜索过的用户。
- **入口**：打开搜索面板且输入为空。
- **步骤**：查看历史胶囊 → 点击某词立即过滤；或点清空删除本用户历史。
- **预期结果**：无历史时不展示历史区块（含清空按钮）；换账号不串历史。

### 场景 3：紧凑顶栏

- **角色**：窄屏或宽度不足导致搜索收成图标的用户。
- **入口**：顶栏搜索图标按钮。
- **步骤**：点击图标打开浮层，浮层内为同一套输入与面板，可继续输入与选择。
- **预期结果**：输入状态在图标 / 浮层切换时保留；选中菜单后关闭浮层。

## 验收标准

- [ ] 数据源是侧栏同一份 `getMenus`，不扫描 `router.getRoutes()`，搜不到 `hideMenu` 公共路由。
- [ ] 只匹配叶子菜单（有 `path` 与 `title`，无子节点或子节点为空）；关键词匹配标题，可命中祖先标题。
- [ ] 空关键词展示历史（若有）以及常用或空态占位；有关键词先出现 loading，再展示「功能」匹配列表；空查询不跳转。
- [ ] 常用由 `header.search.shortcuts` 配置；未配置或列表为空时展示占位文案，不留大块空白。
- [ ] 不渲染高级搜索、「应用」分区或全局快捷键提示。
- [ ] 历史存 localStorage，按用户隔离，去重、上限约 10，可清空。
- [ ] 宽屏聚焦打开面板；点外部 / Escape 关闭；↑↓ 移动高亮，Enter 打开当前项。
- [ ] 紧凑模式复用同一搜索实例；自定义 `header.search.component` 仍整区替换，不受默认面板绑定。
- [ ] 搜索显隐仍只使用 `settings.showSearch` 与现有设置 store。
- [ ] 结果与常用条目同一套卡片样式；标题中匹配关键词使用主题色。
