# 分步弹层的样式需求

## R1 宽屏布局

- 全屏向导顶部显示「关闭」、分隔线与流程标题。头部和页脚固定在弹层内，长内容在正文区域滚动。
- 正文面板最大宽度为 **680px**，含左右各 32px 的桌面内边距。面板在整个弹层内水平居中，左右留白等宽。左侧留白放竖向步骤栏，右侧留白用于保持正文居中。
- 正文标题、表单、选择区和预览都放在同一列。默认浅色主题使用灰色画布与白色工作面，标题、分隔线、文字和交互状态使用现有语义色。深色主题保持同一布局层级。

## R2 页脚按钮位置

- 页脚固定在弹层底部，背景横跨弹层。宽屏操作组以 **680px 正文面板的外右缘**为基准靠右，按飞书实测向内留 5px。各步共用同一右端位置。单排时页脚高 64px，按钮垂直居中，高 32px，常规短文案按钮最小宽度 80px，按钮间距 12px。
- 现有「下一步」放在最右侧，已有「上一步」放在它左侧。末步的「创建」「保存」「完成」等主操作使用同一右端位置。该入口已有的取消、跳过、重试等次要动作放在主按钮左侧，保留次要动作之间的顺序。单独显示一个动作时，沿用右端位置。
- 按钮文案、显示条件、禁用与加载状态以及点击后执行的操作由当前业务决定。长文案或窄容器下允许动作换行，最右端位置保持对齐。

## R3 小弹层与窄窗口

- 「配置成员角色」保持 960px 对话框形态，「添加平台成员」保持 520px 右侧抽屉形态，两者在视口不足时随窗口收缩。正文以各自弹层为基准居中，宽度最大 680px。紧凑布局在面板和弹层之间至少保留左右各 16px，按钮在面板右缘对齐。
- 弹层实际可用宽度小于 1120px 时，步骤导航移到正文顶部，使用紧凑的横向进度。当前步骤的标题始终可见，步骤导航沿用各入口已有的可点击范围和键盘操作。添加平台成员使用共享正文和页脚，保持现有的无步骤栏形态。空间不足时导航项和按钮组换行。
- 正文内的表单、选择区、权限分组和预览在列宽不足时重排为单栏。宽表的横向滚动留在表格内部，标题、控件、焦点和页脚均在可视区域内可达。

## R4 步骤状态样式

竖向导航显示序号、标题和已有简述，以连接线串联。当前步使用主色实心圆，已完成步显示勾，待处理步使用中性色。业务已提供的错误状态继续显示。完成标记与可点击状态分别取自当前入口，表单校验、草稿、预览、取消及退出确认均沿用现行行为。

## 验收标准

| 编号 | 验收方式 |
| --- | --- |
| A1 | 1920px 和 1440px 桌面窗口实测创建组织、租户创建角色与两端用户组向导。正文面板宽 680px，中心与弹层中心偏差不超过 1 个 CSS 像素。测量首步单主按钮、中间步骤「上一步」「下一步」和末步按钮的位置，主按钮右端距面板外右缘 5px，允许 1 个 CSS 像素测量误差。核对页脚高度、垂直居中、按钮间距与次要操作的位置。滚动长权限列表和预览时头脚保持可见。 |
| A2 | 在 1120px、1119px、768px、390px 窗口验证全屏弹层，并在桌面和窄屏分别打开两种小弹层。核对导航布局切换、正文限宽和页脚对齐。长标题、长列表、多个底部动作、宽表及空态均可访问，弹层本身无横向溢出。 |
| A3 | 创建组织覆盖组织资料、所有者、开通、预览。按迁移前的行为回归名称和所有者校验、上一步、预览、关闭和提交，并验证新版全局账号选择器的确认、取消与回显。 |
| A4 | 平台、租户用户组分别验证创建与编辑，包括成员和部门选择、编辑态按条件显示步骤、预览与保存。应用创建内打开菜单编辑，验证详情直达、子弹层返回与外层草稿及焦点恢复。 |
| A5 | 配置成员角色验证选择角色、对象范围和回写成员草稿。添加平台成员验证账号选择、「跳过并添加」、上一步及最终添加。对 18 个迁移组件逐项打开并验证步骤与页脚，角色分配、委派、应用版本和升级覆盖各自的校验、预览、只读或任务状态。 |
| A6 | 在明暗主题下验证主色、完成与错误状态、长正文和固定页脚。使用键盘验证现有可点击步骤、禁用状态、子弹层关闭及焦点行为与迁移前一致。 |
