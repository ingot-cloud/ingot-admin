# 管理台分步弹层统一布局

> 状态：completed

2026-11-06 根据用户确认的飞书布局方向起草。同日用户确认按本规格实施样式和布局调整。

## 目标与范围

平台端与租户端的分步弹层共用一套向导组件。正文最大 680px，在当前弹层内整体水平居中，底部操作以正文面板右缘为对齐基准，按钮位置和间距对照飞书实测。全屏弹层和小弹层按实际容器宽度适配。现有 16 个全屏向导组件和 2 个小型分步弹层都纳入迁移，其中用户组向导覆盖平台、租户两端的创建和编辑入口。

本次限于向导外壳、步骤导航的视觉样式、正文排版和页脚按钮布局。各入口现有的步骤、可跳转范围、校验、按钮行为、关闭处理及业务接口作为迁移回归基线。

## 输入与依赖

- 需求来自 2026-11-06 对话，协作方式为前端独立变更，直接使用对话输入。
- 视觉参照已实测的「企业设置 → 管理员权限 → 创建角色」，重点核对宽屏正文、步骤导航和「上一步」「下一步」「创建角色」的页脚位置。本规格单独定义窄容器和小弹层的适配规则。[飞书官方流程](https://www.feishu.cn/hc/zh-CN/articles/360043495213)
- 创建组织和添加平台成员的账号选择改动见[独立归档](../20261106-base-account-picker/README.md)。工作区联调覆盖了新版选择器，布局提交沿用各入口已有的账号处理。
- 共用组件沿用管理台主题与基础设施。整页配置表单继续按其当前规格工作。[管理台 UI 基础设施](../../../../current/packages/admin-ui-foundation/spec.md) · [整页配置表单布局](../../../../../docs/form-page-layout.md)
