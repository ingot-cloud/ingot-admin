# 需求与验收

1. 访问防护保留一级 Tab；登录失败保护的 IP、设备、客户端、账号 + IP 改为正文内分段选择器，带防护维度标签，使用浅底选中块，与一级下划线 Tab 区分。
2. 选择器、说明与当前策略表单共用 InFormContent 的正文宽度及左右边界，窄窗口允许标签与选择器上下排列，控件不越界；明暗主题均可辨识选中态。
3. 说明各维度可同时启用，选择仅切换查看和维护对象。当前策略有明确标题，默认预览，编辑及保存确认明确所属策略。客户端展示为中文，接口枚举仍为 CLIENT。
4. 切换不预拉其他维度，加载新维度时不显示上一维度的策略；已访问面板保留挂载，查询继续受页面激活及权限约束。
5. 预览或无修改的编辑可直接切换，切换后回到目标预览。有未保存修改时使用框架离开确认，取消保持原维度和草稿，确认放弃后才切换并恢复原策略预览；保存确认及请求期间禁用维度切换，避免错维度提交。
6. 保留只读权限、撤权退出编辑、原字段校验、取消恢复、失败保留草稿和独立保存行为。不扩展到其他页的导航或草稿治理。

验证覆盖四维度、请求顺序、确认取消与放弃、无修改与改回原值、保存成功/失败、只读、宽窄窗口及明暗主题；执行插件单测、类型检查、只读 lint、边界、文档和平台管理台构建。
