# 需求：字段策略按资源接入

## 场景与页面

### 场景 1：平台打开接入

- **角色**：平台管理员
- **入口**：应用目录中的资源编辑
- **步骤**：编辑服务器允许的租户资源，打开字段策略接入并保存
- **预期结果**：开关可用并保存。服务器不允许、非租户域或没有字段的资源不能打开

### 场景 2：租户配置已接入资源

- **角色**：具备字段策略权限的租户管理员
- **入口**：安全与合规 / 字段策略
- **步骤**：在左侧选择已接入资源，在右侧添加或编辑一条规则并确认
- **预期结果**：候选项只来自该资源的字段能力和动作。当前只有成员。确认后立即保存，再次进入仍是该配置。页面不展示默认策略版本标识

### 页面结构

左侧是已接入资源，右侧是该资源的规则表。只有一项时仍显示该项。添加、编辑和删除确认后直接保存整份策略。对话框区分可见性规则与操作规则。查看者的成员和部门都用选择对话框，部门标签可标「含下级」。目标范围默认全部对象，一条规则只配一个范围；管理部门和指定成员分别用部门树、成员对话框。字段、动作、可见性都用选择控件，不手填编码。去掉场景。

平台资源编辑在字段能力附近增加接入开关。不允许接入时开关不可用。

## 验收标准

- [ ] 菜单名称为字段策略，进入后看到成员资源的字段能力
- [ ] 不能手填字段键，也不能选择成员资源没有的动作
- [ ] 保存和再次加载不包含场景
- [ ] 平台不能给未声明运行能力的资源打开接入开关
