# 需求

- 创建组织的所有者字段和添加平台成员的账号字段都通过点击打开单选弹窗。确认后在字段内回显登录名，取消保留表单已确认的值。
- 弹窗布局对齐平台角色分配中的成员选择。左栏搜索和展示候选，右栏回显已选账号，支持移除和清空。选中另一账号时替换右栏草稿，搜索其他账号时保留已选项。
- 具备全局账号读取权限时，打开弹窗加载首屏，每页 20 条，支持翻页。清空登录名筛选后返回第一页。仅具备精确查找权限时可继续使用完整登录名查询。
- 从分页列表选中账号时，按当前用途校验账号。校验通过后才进入右栏草稿，查询失败或未命中时给出反馈。
- 添加平台成员的分页候选和总数排除已有平台成员资格的账号，包含暂停、已移出。租户所有者候选沿用普通账号分页。
- 添加平台成员继续提示账号已有成员资格。查不到时可前往创建全局账号。确认账号后按原有字段权限展示和编辑成员资料。
- 创建组织继续允许使用已经是平台成员的账号作为所有者。创建流程按原有接口提交所选账号 ID。
