# 平台创建流程的全局账号选择

> 状态：completed

2026-11-06 用户指定两处交互对齐现有人员选择方式，在对话框内精确查询并选择全局账号。变更限于平台插件中的创建组织第二步和添加平台成员第一步。

用户进一步指定以平台「角色分配 → 分配角色 → 选择成员」弹窗为参照。两处账号弹窗采用左候选、右已选布局，沿用单账号约束和完整登录名查询。

用户要求弹窗打开时默认返回分页账号列表。复用账号列表读取权限和精确查找的用途校验。

添加平台成员的分页候选和总数排除已有平台成员资格的账号。创建组织的所有者仍可选择这些账号。
