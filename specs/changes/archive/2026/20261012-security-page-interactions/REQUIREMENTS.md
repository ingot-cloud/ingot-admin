# 需求与验收

1. 各 Tab 仅在激活时触发自己的查询。凭证策略共享后端唯一整组列表接口的一次读取，类型表单懒挂载；登录失败维度使用已有单项接口。切走后禁止后台刷新或保存后拉取隐藏内容；身份与授权变化仍隔离缓存。编辑控件的目录选择器只在需要编辑时挂载。
2. 已有策略默认预览，使用 `InForm` / `InDetailField` 展示文本与枚举含义；编辑后显示输入控件和取消、保存。取消恢复服务端数据，保存失败保留草稿，保存成功刷新相应数据并返回预览。新建策略直接进入编辑。已有策略详情抽屉同样默认预览。只读角色无编辑入口，写处理器检查精确权限；失去写权限退出编辑。
3. 账号管理员与会员策略独立保存；凭证各类型独立保存。切换已访问 Tab 可保留其局部状态，但隐藏内容不发请求。固定密码预览仅展示已设置/未设置，不显示明文。
4. 使用框架页面、表单、表格、抽屉及主题 Token，表单响应式排列，长文本换行，路径编辑器与工具栏可收缩。页面头与 Tab 固定，策略内容滚动；表格工具栏与分页固定，表体滚动。480px 和常规宽屏、明暗主题均不发生页面横向溢出。
5. 保留现有路径、接口、枚举、校验、永久锁定仅管理员、路径/分组互斥、GLOBAL 并发策略不可删除、会话下线与策略生效规则。会话详情属于只读信息，无额外编辑态。

验收：真实 Vue Query 请求门控单测；浏览器隔离接口验证激活 Tab 的请求、预览/编辑/取消/保存与只读角色、窄屏主题和容器边界；插件单测、类型检查、只读 lint、依赖边界与平台宿主构建。真实部署由用户人工验收，不提前更新 current。
