## 凭证策略容器验收修复

2026-10-12 用户截图显示预览态编辑按钮，以及编辑态保存按钮、特殊字符集和弱密码控件被右侧裁切。新增实际元素矩形检查后，旧实现于 1308px 密码强度预览态复现失败：内容区超出页面 body。

根因是凭证页面 `InLoading` 的 100% content-box 宽度加上左右各 20px 内边距。页面私有样式改用 border-box，补齐可收缩宽度约束，将内边距计入总宽度。回归直接比较页面 body、内容区及可见按钮/录入/展示字段的左右边界，同时验证内容区内边距；保留既有滚动宽度检查。接口与公共组件不变。

修复后平台宿主构建、security 插件类型检查及只读 lint、变更文件格式检查、`git diff --check` 均通过。安全中心 7 个浏览器用例全部通过（48.3s），新增回归覆盖四个 Tab 在 1308px / 1024px / 480px 明暗主题下共 48 个预览/编辑状态。实际元素边界检查全部通过，并人工查看密码强度 1308px 预览/编辑及 480px 编辑截图，按钮、特殊字符集、弱密码录入框均保留容器内边距。该阶段仅修复页面私有样式，既有请求与交互回归通过，未重复执行无关后端或单测。

## 凭证策略数字字段验收修复

2026-10-12 用户提供五条 `ElInputNumber modelValue` 类型 warning。历史 Security 初始化数据的 `minLength`、`maxLength`、`checkCount`、`warningDaysBefore`、`graceLoginCount` 为数字字符串，页面此前直接复制到表单。开发模式夹具使用这些返回值，旧实现进入密码强度编辑态即复现 `Expected Number | Null, got String`。

配置进入 `PolicyTabPanel` 表单时按策略类型统一转换数字字段；初始密码的 `length`、`validHours` 同样处理。仅转换指定字段，不修改查询缓存，保留非数字字段和未知配置，取消时再次从服务端快照转换。有限数字和数字字符串转换为 number；空白、非法数值、非数字类型留空交给原有校验，保留有效的零及缺省字段。未修改后端接口和数据库。

验证结果：

- 新增数字类型兼容单测 6 个；security 全部 16 文件 / 38 用例通过。
- 使用 `SECURITY_UI_DEV=1` 的开发模式浏览器用例通过（10.7s），明确捕获 Vue warning；四个 Tab 编辑、取消再编辑、保存均无 Vue warning，保存请求的数字字段为 number，原有其他配置保留。生产构建会移除 Vue 开发警告，因此增加开发模式验证。
- 平台宿主重新构建后，全部 8 个安全中心浏览器回归通过（51.9s），包括既有请求门控、保存失败、只读权限、抽屉与布局用例。
- security 类型检查、只读 lint、变更文件格式检查、`git diff --check` 通过。
- 测试只拦截 URL pathname 的 `/api/` 前缀，避免开发模式下误拦截源码模块的 `src/api/` 路径；所有业务 API 完全隔离，未写入真实配置。
