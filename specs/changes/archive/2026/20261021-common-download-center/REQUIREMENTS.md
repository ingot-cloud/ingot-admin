# Requirements

## 用户场景

1. 管理员在「批量导入或导出」页选择范围并确定导出，对话框关闭，提示「导出任务已提交，可在我的下载中查看」，提示内带「前往我的下载」链接。
2. 管理员点击顶栏下载图标进入「我的下载」，查看自己的导出任务并下载已完成的文件。

## 页面与交互

### 顶栏入口

- 功能小部件区新增下载图标（tooltip「我的下载」），位于通知前
- 点击跳转 `/downloads`；不需要菜单配置与权限码

### 我的下载页

- 页头标题「我的下载」，副标题「导出文件保留 7 天，过期后需重新导出」
- 表格列：文件（名称 + 文件名）、来源、状态、大小、创建时间、过期时间、操作
- 状态标签：排队中、生成中、可下载、失败、已过期；失败时悬浮显示原因
- 操作：仅「可下载」显示「下载」，点击获取链接后触发浏览器下载；按钮在请求期间 loading
- 列表含进行中任务时每 3 秒静默刷新当前页，全部终态后停止；离开页面停止
- 分页；空状态「暂无下载记录」
- 时间按当地时区展示

### 成员导出

- 确定后只等待提交接口返回，不再轮询任务、不自动下载
- 「部分成员」范围展开与空范围提示保持现状

## 验收标准

- [ ] 顶栏出现下载图标，点击进入「我的下载」，刷新页面仍可访问
- [ ] 发起成员导出后立即提示并可从提示进入「我的下载」，新任务位于首行
- [ ] 进行中任务自动刷新为「可下载」，点击下载得到 xlsx
- [ ] 失败任务显示原因，过期任务不可下载
- [ ] 无导出权限后下载提示无权限
- [ ] 导入、导入历史、错误报告与一次性密码下载不受影响
