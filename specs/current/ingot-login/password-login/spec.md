# 同源密码登录与身份切换规格

## 宿主与入口

租户 `apps/admin`（tenant-admin/TENANT）、平台 `apps/admin-platform`（platform-admin/PLATFORM）独立组合 auth-plugin；`/login/` 是公开静态路由，无后台布局、无需先拉业务 bootstrap。双域名与纯 IP HTTPS 双端口使用同一页面逻辑，全部认证/API请求固定当前 origin。

无独立 auth/auth-platform App，无浏览器 ticket/complete。旧 `/auth/start`、`/auth/complete`、`/oauth2/challenge` 只清参数并进入本应用 `/login/`。禁止外部回跳或浏览器指定 domain/clientId。

## 登录与长期停留

普通打开登录页无恢复事务时只核对一次 me：401留表单，有效会话走一次 bootstrap进入管理。显式退出/切换组织强制表单，跳过旧会话自动进入。停留、聚焦不创建登录事务或定时续期。

点击后合并同一次提交：csrf → 创建事务 → whole HYBRID login。平台和单组织直接完成，多组织在同页选择后 select；选择前清掉密码内存。成功后本次事务 GET → me → bootstrap各一次，再进入管理页。平台不调用租户select。首次加密可读取公钥，412才触发公共挑战。

账号/密码错误留表单、结束loading，下一次明确提交创建新事务。处理中不能反复提交；显示准确业务文案，503不当作过期或强制退出。

## 恢复

本标签页仅存 appId命名的事务线索与安全相对深链；密码、Token、sid、PKCE和候选快照不持久化。刷新时恢复原绑定下事务，不导入query中的事务或他人结果。

恢复得到的同一服务端COMPLETED对象可用于一次确认，不紧接着重复GET；POST完成响应仍须GET本次结果。sessionEstablished必须对应本次结果，旧me有效不能代替；未建立时仅一次resume再核对。me仍确认真实Cookie交付与应用域。

结果不确定只读同一事务，最多15次且总预算15秒，不盲目重交密码/选择。结果过期或不可恢复回表单；Cookie始终不可用明确提示并停止循环。

## 进入、页面挂载与旧请求

公开登录页独立于按身份/权限代次重建的KeepAlive，bootstrap和菜单变化不重挂表单。提交、选择、恢复、确认与宿主进入合并在途任务；相同路由指纹不重复安装。

切换身份先暂停受保护页面，清旧用户、权限、菜单、Query、详情和表单，bootstrap与导航完成后再挂载新身份内容。强制改密先进入/init受限流程；无菜单显示稳定无权限空态，不循环登录。

HTTP异步指纹/CSRF/信封准备前后、业务码/401响应处理前核对身份纪元；旧成功、失败及挑战/公钥重试不能用新身份发送或回填。旧状态/能力任务结束不得清除新身份在途任务。业务触发改密检查与跳转合并。

## 切换组织、退出与多标签页

切换组织显式强制表单，保留安全相对深链；打开表单不撤销旧会话。新组织无原页面权限时显示无权限，不反复跳转。

显式退出csrf→DELETE logout各一次，合并退出和导航，最长1500ms并AbortSignal中止；只清当前应用身份。退出清returnTo，业务401本地清理不再请求远端退出，保留安全深链并强制表单，避免登录页多一次me。并发签退只弹一次提示，取消不退出。

同origin BroadcastChannel区分新身份与logged-out：活动管理标签收到新身份只bootstrap一次；登录表单清旧上下文而不自动提交或进入。收到退出直接清理并进强制表单，不发me/bootstrap/logout、不重复广播。不同应用origin不共享通知。

同IP端口会发送两套应用Cookie；浏览器按origin隔离存储/通知，服务端选择当前应用Cookie。前端不读取HttpOnly值、不自行签发认证Cookie。

## 依赖与验收边界

登录使用既有共享品牌、表单、键盘与配色策略，离开登录恢复管理台主题，默认light配置不覆盖持久管理偏好。公共挑战每宿主只有一个ChallengeHost，PassToken只走Header。

两端登录、退出、切换组织、多标签页已由用户本地确认，精确次数与异常分支另有121项前端定向和22类受控浏览器证据。真实CA/休眠、实际策略故障和生产回滚另行验收，不写成已执行。DTO/接口唯一副本见归档API，不在本基线平行维护。
