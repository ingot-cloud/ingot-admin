# 浏览器会话上下文规格

## 身份确认与请求固定

HttpOnly Cookie由后端设置，前端不读取值或持久化AT/RT/sid。`AuthApi.me`只查询实际Cookie身份，无隐式全局更新。admin-core宿主校验app/domain、contextVersion后同步清理与接纳，身份改变先推进纪元并暂停旧页面，再允许新业务请求；初次或焦点重验不能借新版本保留旧权限。

HttpClientHooks的onRequestCreated在公共请求调用时同步记录纪元、contextVersion、暂停状态及只读bootstrap标志；异步CSRF/指纹/信封准备、重试和响应不能改绑。租户请求发送捕获版本，网关冲突409不转发；旧成功、401和重试在错误处理前按取消丢弃，业务写不自动重放。通用http-client仅暴露可选同步钩子，业务身份逻辑由宿主注入。

## 注销确认

退出固定请求创建时的contextVersion，CSRF准备和重试不读取新身份替代原意图。本地持久化非敏感pending-logout线索；超时/503等未知结果不得视为成功，保留待确认并暂停业务，跨标签同步，恢复可见或刷新后继续确认原退出。

只有后端持久撤销确认才完成退出；200不发送正式/绑定Cookie删除，浏览器不能按“Cookie仍存在”判定旧身份有效。成功后当前应用清理身份/Query/UI并进入表单，清深链；不同origin另一应用不受影响。迟到旧退出响应不得清理并发新登录。

## 恢复、广播与错误

登录/切换只恢复本次仍为当前结果的同一事务；凭据变更、注销或新登录后旧结果拒绝。BFF认证端点错误由认证流处理，不递归远端注销。切换期间401先结合pending事务和实际me确认；contextVersion变化或漏广播时清理旧权限后加载新身份，真正失效才进入表单。

BroadcastChannel/storage仅传非敏感事务/阶段/版本，不传凭据，不替代服务端校验；不同origin隔离。完成后的目标bootstrap每标签每代一次，失败保留新身份和可重试入口，不还原旧组织数据。强制改密及无权限空态继续受既有安全门禁。

## 服务契约与发布

浏览器协议、R响应与UTC时间沿归档接口副本；服务端表、密钥和撤销规则由[后端账本](../../../../../ingot/specs/current/security/session-ledger/SPEC.md)维护，前端不维护平行权威契约。原登录截止对切换、恢复、refresh和Cookie都有效，浏览器不续造期限。

无性能或目标环境生产就绪通过声明。相关独立Spec继续保持发布阻断；当前实现归档不解除门禁。
