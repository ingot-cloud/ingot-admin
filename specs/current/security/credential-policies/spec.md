# 凭证策略规格

## 概述

平台安全管理员在 `/security/credential-policies` 维护凭证策略，canonical viewPath 为 `security.credential.policies`。页面属独立安全中心应用，权限与接口见归档 [API.md](../../../changes/archive/2026/20261012-iam-platform-capability-completion/API.md)。

## 用户场景

- 具有 `iam-platform:credential-policy:read` 的人员打开页面，查看激活类型的策略预览；四类型表单按需挂载，共享后端现有整组列表查询
- 具有相应维护权限的人员显式进入编辑，取消恢复服务端快照；保存失败保留草稿，成功刷新相应数据并回到预览，各类型独立保存
- 只读角色没有编辑入口，撤销写权限后退出编辑。固定密码预览仅显示已设置/未设置

## 功能需求

- 系统 SHALL 使用已有列表读取接口，禁止调用未实现的单类型读取端点；隐藏面板不发请求，编辑选择器仅在需要时挂载
- 系统 MUST 保留字段校验与精确维护权限，在提交处理器复核权限；取消恢复、失败留草稿和成功预览形成完整闭环
- 系统 SHALL 将历史配置中指定数字字段的有效数字字符串转换为表单数值，保留非数字字段与未知配置，不改写查询缓存；空白或非法数字留空交给校验
- 系统 SHALL 使用 InFormContent：默认最大宽度 840px、居中、窄容器收缩；普通字段两列，长文本整行，短选项可三列，窄屏一列；预览/编辑及操作区共用正文边界
- 页头与页级 Tab 保持工作区宽度，正文滚动；输入、长文本与按钮不得被容器裁切
