# 我的下载规格

本文写已验收的页面行为。接口字段见归档 [API.md](../../../changes/archive/2026/20261021-common-download-center/API.md)。

## 概述

「我的下载」是管理台公共页。租户用户查看本人导出记录、状态和失败原因，并对可下载文件发起下载。文件保留 7 天。

## 范围

### In Scope

- 租户管理台顶栏「我的下载」入口与 `/downloads` 页面
- 分页列表、状态、失败原因、进行中自动刷新、成功行下载
- 成员表格导出提交后的前往提示

### Out of Scope

- 平台管理台入口
- 导入历史、错误报告、一次性密码
- 成员 JSON 导出、删除任务、重新生成

## 用户场景

### 场景 1：查看并下载

- **角色**：已登录租户用户
- **入口**：顶栏「我的下载」，或地址 `/downloads`
- **步骤**：查看列表；对「可下载」行点击下载
- **预期结果**：只显示本人任务。下载打开短时链接。排队、生成中、失败、已过期的行没有下载按钮。失败行显示原因。无记录时显示「暂无下载记录」

### 场景 2：等待生成完成

- **角色**：刚提交导出的用户
- **前置条件**：当前页有排队或生成中的任务
- **步骤**：留在「我的下载」
- **预期结果**：约每 3 秒静默刷新当前页，不出现整页加载。全部结束后停止刷新

### 场景 3：提交成员表格导出

- **角色**：具备成员导出权限的用户
- **入口**：成员导入导出页的导出
- **步骤**：选择范围并确定
- **预期结果**：对话框关闭，提示导出已提交。可前往「我的下载」，也可留在当前页。本页不再轮询或直接下载该文件

## 功能需求

### REQ-001：入口与页面

系统 SHALL 在租户管理台顶栏提供「我的下载」，并打开主布局下的隐藏菜单页 `/downloads`。

**验收标准：**

- [x] 入口位于通知之前，文案「我的下载」
- [x] 页头说明导出文件保留 7 天，过期后需重新导出
- [x] 平台管理台不出现该入口

### REQ-002：列表与下载

系统 SHALL 按创建时间倒序分页展示任务，默认每页 20 条，并只允许下载已成功且未过期的文件。

**验收标准：**

- [x] 列包含文件、来源、状态、大小、创建时间、过期时间
- [x] 时间按当地时区展示
- [x] 下载按行显示加载；链接失败时刷新列表
- [x] 切换身份后不复用上一身份的列表缓存
