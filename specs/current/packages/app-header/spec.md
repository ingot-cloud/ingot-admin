# 顶栏 APP 配置规格

本文写已上线的默认顶栏行为。主题外壳见 [管理台主题](../admin-theme/spec.md)。视觉基线见 [管理台 UI 基础设施](../admin-ui-foundation/spec.md)。接入示例见 [docs/app-header.md](../../../../docs/app-header.md)。前端公开配置见归档 DESIGN.md，不要在此维护完整类型表。

## 概述

`bootstrapAdminApp({ header })` 声明品牌、大类、搜索、小部件和用户菜单。组件与回调只经应用注入传递，不写入可序列化运行时配置或 Pinia 持久化。省略列表使用默认值（小部件：全屏、设置；用户菜单：切换组织、修改密码、退出登录）；显式数组视为完整列表，空数组清空。租户管理台额外放入「我的下载」，见 [我的下载](../download-center/spec.md)。搜索显隐仍只使用 `settings.showSearch`。

## 范围

### In Scope

- 五区布局、品牌与侧栏宽度对齐、大类入口与分组面板、宽度驱动收纳
- 已授权且可导航应用的快捷入口、分类面板及路由/侧栏联动
- 内置与自定义小部件、用户入口与菜单扩展
- 默认菜单搜索：`getMenus`、历史、常用、键盘与紧凑浮层
- 旧 `InAppBar` 插槽与 `utilities` prop 兼容

### Out of Scope

- configured 模式大类与侧栏的业务分组、系统切换或路由恢复（由 APP `onSelect` 自行联动）
- 后端应用分类模型、应用授权变更、拖拽排序与常用应用持久化
- 后端全局搜索服务、扫描 `router.getRoutes()`、全局快捷键
- 自定义 `header.search.component` 整区替换后的默认面板绑定
- `apps/auth` 登录应用顶栏

## 用户场景

### 场景 1：使用五区顶栏

- **角色**：已登录用户
- **前置条件**：应用使用默认主题顶栏，已配置或沿用默认 `header`
- **步骤**：浏览页面、收起侧栏、调整窗口宽度、打开分组菜单或小部件
- **预期结果**：品牌右边界与侧栏对齐；收起仅 Logo；入口保持可达，无整页横向滚动或重叠

### 场景 2：按菜单名跳转

- **角色**：有侧栏菜单权限的用户
- **前置条件**：`settings.showSearch` 开启，未替换 `header.search.component`
- **步骤**：聚焦搜索框 → 输入菜单名 → 鼠标或 ↑↓ / Enter 选择
- **预期结果**：面板关闭并 `router.push` 到该菜单 path；非空关键词写入本用户搜索历史

### 场景 3：查看搜索历史与常用

- **角色**：同一浏览器上曾搜索过的用户
- **前置条件**：打开搜索面板且输入为空
- **步骤**：查看历史胶囊或常用入口；可清空本用户历史
- **预期结果**：无历史时不展示历史区；未配置常用时展示空态占位；换账号不串历史

### 场景 4：紧凑搜索

- **角色**：窄屏或宽度不足的用户
- **前置条件**：搜索已收成图标
- **步骤**：点击图标，在浮层内继续输入并选择
- **预期结果**：与宽屏同一套输入实例；选中后关闭浮层

### 场景 5：切换更多应用

- **角色**：可访问多个应用的已登录用户
- **前置条件**：使用 `navigation.source: "applications"`，授权且有可导航菜单的应用超过直出上限
- **步骤**：hover 最后一个快捷应用或操作其右侧箭头 → 从分类面板选择溢出应用
- **预期结果**：进入该应用首个可导航菜单，当前应用高亮和侧栏同步；所选应用优先成为快捷入口，面板不重复展示直出应用

## 功能需求

### REQ-001：五区与 APP 配置

系统 SHALL 将默认顶栏划分为品牌、大类菜单、搜索、功能小部件、用户入口，并由 APP `header` 配置内容。

**验收标准：**

- [x] 不传新配置时保留品牌、搜索开关、全屏、设置及默认用户菜单
- [x] 列表省略用默认；显式数组替换；空数组清空
- [x] 可见、禁用、选中、角标可响应更新；组件与回调不持久化
- [x] 条目 `type` 按区域使用不同常量；`Component` 只属于小部件

### REQ-002：大类菜单与分组

系统 SHALL 支持直接入口与分组面板，并以可用宽度决定直出项。

**验收标准：**

- [x] 分组 hover / click（缺省 hover）；组标题灰字加底部分割线；组内可 `columns` 或按数量折列（每列最多 8 行、最多 4 列）
- [x] 优先保留当前选中入口；可见入口非空时至少一个直出
- [x] 未直出入口进入更多浮层，分组在更多中仍可进入内容
- [x] configured 模式的核心不自行过滤侧栏或跳转业务路由；applications 模式沿用应用选择链路联动路由与侧栏

### REQ-003：小部件、用户区与降级

系统 SHALL 让功能区与用户区独立于导航测量，宽度不足时按序收纳。

**验收标准：**

- [x] 桌面品牌宽度与侧栏 Token 对齐；收起隐藏标题；窄屏 overlay 显示导航开关与 Logo
- [x] 放不下时先把搜索变图标，再从右向左收纳小部件；自定义组件不重复挂载
- [x] 用户入口在最右侧；可排序/隐藏内置项并追加动作与分割线；菜单为空时保留头像、无空下拉
- [x] 修改密码为对话框，不是抽屉

### REQ-004：默认菜单搜索

系统 SHALL 在未替换搜索组件时，按与侧栏相同的已授权菜单做本地过滤。

**验收标准：**

- [x] 数据源为 `useRouterStore().getMenus`，不扫描 `router.getRoutes()`，搜不到 `hideMenu` 公共路由
- [x] 只匹配叶子；关键词可命中标题或祖先标题；空查询不跳转
- [x] 空关键词展示历史（若有）与 `header.search.shortcuts`；未配置常用时占位，不留大块空白
- [x] 输入后先 loading，再展示「功能」列表；命中词主题色高亮
- [x] 历史按用户隔离、去重、上限约 10、可清空
- [x] 宽屏聚焦打开面板；Escape / 点外部关闭；↑↓ / Enter；紧凑模式复用同一实例
- [x] 不提供高级搜索、「应用」分区或全局快捷键

### REQ-005：应用快捷入口与分类面板

系统 SHALL 在 applications 模式下展示已授权且有可导航菜单的应用，默认最多直出两个，通过最后入口的箭头访问其余应用。

**验收标准：**

- [x] `maxVisibleItems` 缺省或不是正整数时回退 2，正整数配置可覆盖；宽度不足继续收纳，非空时至少直出一个，configured 模式保留既有默认
- [x] 存在溢出应用时，箭头连接在最后快捷入口右侧；名称按钮切换自身，独立箭头按钮只开关面板，无溢出应用时不显示箭头
- [x] hover 整项展开，进入面板保持，离开触发区和面板后延迟 160ms 关闭；展开时浅灰背景及向上箭头，关闭时向下
- [x] `applicationGroups` 按稳定应用 code 匹配分类，分类跟随配置顺序，组内沿用 bootstrap 排序；空组不渲染，未知或不可访问的 code 不生成入口，重复分类 key / 应用 code 显式报错
- [x] 无分类配置时使用“应用”，已配置分类的未匹配项进入“其他应用”；面板只展示实际溢出项，灰字标题和底部分隔线跨该组所有列
- [x] 组内按列优先排列图标及名称，支持显式 columns；缺省按实际溢出项每列最多 8 行、最多 4 列折列；窄屏单列、面板位于视口内并可纵向滚动
- [x] 保留当前应用优先；默认 A/B 直出时选择 C，成功切换后变为 A/C，B 进入更多；刷新、深链接和搜索导航同步高亮及侧栏，路由未成功时不提前更新应用上下文
- [x] 授权或 bootstrap 更新后打开面板立即同步；图标缺失或加载失败保留默认回退，强制改密时不挂载应用导航和面板
- [x] 箭头有可访问名称、aria-expanded 和面板关联；Enter / Space 开关，Tab / Enter 选择，Escape / 外部点击关闭，键盘关闭恢复焦点，hover 不抢焦点
- [x] 应用面板与搜索、小部件互斥；configured Group / Action、旧插槽及自定义 header 主题兼容，旧插槽单独溢出时仍可访问

## 非功能需求

- 浮层支持键盘、Escape 关闭与焦点恢复；禁用项不可触发
- 宽度变化批量测量，避免临界抖动
- 自定义 `theme.parts.header` 仍可整区替换，并通过 `useAdminShell().header` 读取配置
- 路由更新及最后快捷应用变化时保持收纳和键盘焦点；长应用名、关闭浮层及测量区不撑宽页面

## 依赖与约束

- 搜索显隐唯一来源：`settings.showSearch`
- 菜单数据已按权限裁剪；历史键用用户 phone/email，无标识时匿名桶
- 图标生产离线见 [Iconify 离线打包](../iconify-offline/spec.md)
- 应用入口来自 IAM bootstrap 和现有可导航菜单；前端分类配置不扩大授权集合，不新增后端接口

## 验收标准

- [x] 默认顶栏五区可用，未配置 APP 仍有品牌/搜索/全屏/设置/用户菜单
- [x] 分组菜单可折列，窄屏可访问入口与收纳功能
- [x] 默认搜索能按菜单名跳转，历史与常用符合上述规则
- [x] 多应用默认两项快捷入口、末尾箭头、hover 分类布局、应用切换和窄屏交互通过验收（2026-10-13 用户确认）
