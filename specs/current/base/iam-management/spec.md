# IAM 管理页面行为

## 身份与入口

admin 与 admin-platform 是独立同源宿主，登录为本站 /login/，通过本站 BFF 建立会话。平台无租户选择；租户单候选自动进入，多候选先选择。bootstrap 校验预期域，切换成功清理旧权限、草稿和缓存，旧 contextEpoch 的迟到响应不能回填。登录、退出、多标签页和安全返回沿[密码登录](../../ingot-login/password-login/spec.md)。

初始改密只展示受限品牌/账号入口与表单，不加载业务菜单和浮层。密码请求沿 HYBRID whole，加密错误、确认不一致或策略失败保持受限；成功退出旧会话后重新登录。正常用户沿现有导航和搜索设置。

## 导航与异常

顶栏按服务端可访问应用及图标展示，最多两个直出、其余更多；切换应用后侧栏只显示本应用菜单。无菜单应用无空入口。刷新、深链、搜索与前进后退保持当前应用。没有额外应用目录请求补齐导航权限。

菜单高级配置区分隐藏、缓存、路由名及有序参数，详情可只读或独立编辑；隐藏页仍按 ACTION 注册。query/hash 与记录路径的缓存语义分开，缓存上限 20，撤权后旧页面移除。非法重复路径/路由名不降级放行；首屏及刷新进入恢复页、清除业务路由，提供重试/重新登录。修复后回安全目标并保留 query/hash，历史后退不恢复旧业务路由。

## 角色、分配与委派

角色目录、分配和授权管理员分别按资格显示/取数，Tab 仅请求当前激活面板。关联成员/组独立分页，来源按实际直接/组贡献展示并去重，不通过父列表 ids 回查代替关系接口。

平台固定版本不随发布隐式升级，单条/批次显式选择目标、对象范围、预览及确认；更晚发布不替换已选目标。租户与共享角色为当前完整权限，保存即时生效，旧租户版本/差异页退出。详情、授权列表及诊断使用当前契约，不恢复旧入口。

治理、纯委派和兼具资格分别显示真实授权依据。纯委派使用本人一个来源，候选仅显示其允许版本、对象、接收主体和期限。对象选择跨页保留完整 ID，确认更新草稿，取消保持原配置；更换某角色版本只清理该角色无效范围与旧预览。逐资源范围与字段编辑、批量覆盖须保留确认和跨资源隔离。

列表按服务端筛选和总数分页，换条件回第一页。五种分配状态与有效区间一致，分配/委派按大 ID 倒序；纯委派仅见本人来源。用户列设置分 Tab 保存，不用首屏样本决定整列字段权限。

## 成员、字段与角色编辑

普通只读成员不能编辑；字段编辑者只提交其当前对象和精确操作允许的字段。HIDDEN 无标签、值及输入；MASKED 只读显示服务端值，不回传掩码；未触碰字段不提交，明确清空只提交允许的 null。创建候选不披露账号联系方式，不可写显示名使用服务端默认。

平台联系资料与全局账号/租户资料独立，清空不回退。成员角色两步编辑先留草稿，按新增/调整/撤销差量与资料一并保存，未加载的分页记录不被清除；固定旧版本可显式分配，组继承和委派摘要只读。资料只读但具备目标编辑及直接授予资格时可单独提交角色差量。

列布局与用户偏好分离：初始化不写 localStorage，主动隐藏/排序后保存；旧不完整顺序补新列，暂不可见字段的偏好保留。权限刷新新增列可出现，撤权列移除，用户设置不能恢复无权字段。逐行 fieldAccess 控制每个对象，第一页无可见样本不能删除潜在允许列。时间点模型保留带偏移 ISO，UTC 响应按用户时区展示，无法识别时回退上海；未获权限不显示只读时间。

## 草稿、预览与错误

编辑有未保存修改时离开须确认，未改动直接关闭。范围、字段或上下文改变使预览失效；写请求防重复，不自动重放 mutation。409 保留草稿并要求重验；503 不伪装为空或登出，保留草稿、失效旧预览并提供恢复。403 后按最新读取能力：仍可读保留可见草稿但禁保存，失去读取权关闭详情；404 不披露隐藏对象。

权限刷新 single-flight，无逐行鉴权 RPC，不从角色名放行。主题、窄屏、InLoading、危险确认及只读详情沿公共组件规范。抽屉窄屏不超视口，列表筛选/创建入口不互相遮挡。

## 导入导出及辅助能力

成员 JSON 导出与工作簿分开；下载中心处理工作簿任务及签发，失败、过期、撤权不展示成功。导入显示逐行结果，不能把部分行失败改成整份回滚。成员/部门/组/设置/所有者转交、人群、资源字段策略、诊断和审计使用各自权限、对象与错误规则。

平台字典、发号、社会化配置和全局账号保持现行 IAM 契约；Security、Member、OSS 仍按所属服务。社会化全局记录允许无 tenantId，旧记录归属保留。普通通讯录、旧 PMS 调用、平台独立字段策略、未发布审计导出和旧四站登录不再作为页面入口。
