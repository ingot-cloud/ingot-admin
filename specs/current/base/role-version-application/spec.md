# 角色版本信息与批量应用

## 角色与版本展示

平台、共享和租户角色统一显示版本信息。已命名版本展示为“v3 · 客服日常权限”；未命名及历史数据回退 `vN`。名称不是标识，选择、发布和应用均使用固定版本 ID；系统角色只读。

角色详情提供版本历史及权限编辑入口，展示版本名称、备注、发布时间与权限差异。平台自定义角色在独立治理资格允许时提供应用版本和应用任务记录，并区分“最新发布版本”与“分配版本分布”。角色分配、成员绑定及相关版本选择器共用可读版本格式。

版本名称和备注通过独立弹窗编辑，名称最多 128 字、备注最多 512 字，携带元数据乐观锁；成功后刷新展示，不发布权限版本、不修改分配。并发冲突显示接口反馈，不静默覆盖。

## 历史来源与权限编辑

支持从同一角色的历史版本进入编辑，编辑状态与原版本隔离，完整保留操作授权、参数、租户定制差异和字段权限。请求携带来源版本 ID，租户共享基础由后端按该固定来源校验。

创建和发布填写版本名称及备注。平台自定义角色发布默认仅发布；具备独立分配升级资格时可以选择替换指定来源版本的分配或应用全部关联分配。发布与应用分别反馈：新版本已发布但应用预检受阻时，展示已发布版本及待处理原因，不提示应用成功。

共享和租户角色支持版本元数据及历史编辑，但不提供跨租户或租户批量应用入口。本轮没有持久角色草稿。

## 应用向导

平台角色版本历史中的“应用此版本”可选择更高或更低已发布版本，复用同一向导。流程包括确定集合、配置范围、预览影响和确认执行。

集合支持全部关联分配、指定来源版本和指定分配；候选由后端分页，页面不拉取全部用户，也不将用户组展开为成员分配。前端仅显示后端治理范围内的对象和统计。

范围默认保留后端判定兼容的原绑定。公共范围选择器支持逐条补齐及对明确选定集合批量覆盖；新增或不兼容参数必须处理。候选选择采用分页组件，不要求手工输入裸 ID。排除记录需要明确操作，调整后刷新预检结果。

影响预览展示操作、范围表达式、绑定和字段权限差异及逐条冲突。存在 BLOCKED 项时不能确认执行；重新预检后的 READY 计划携带最新乐观锁和幂等键确认。

## 任务状态与继续处理

任务记录和详情展示目标发布版本、当前状态、成功及未完成数量、冲突原因和分页明细。RUNNING 后显示异步进度，角色详情刷新不会销毁正在展示的任务结果。

任务暂停时保留已经成功的数量与明细，明确显示剩余待处理项；支持重新预检和配置后再次确认继续。继续只处理未完成项，不提供自动回滚已完成分配。存在待处理或失败项时，不展示全部成功。关闭页面不停止后端任务。

版本发布、应用确认及任务最终完成是不同反馈时点。治理资格变化或并发冲突按服务端结果显示，不通过前端按钮状态代替后端授权校验。

## 公共组件与页面约束

版本展示、版本信息表单、元数据弹窗、详情及应用向导由 admin-common 复用。platform 插件负责平台及共享角色 API 接线，org 插件负责租户角色 API 接线，没有跨插件直接依赖。

交互采用框架标准组件及主题 Token，支持明暗主题和窄屏；大量分配使用分页。接口时间点保持带时区 ISO-8601，发布时间按公共当地时区格式化工具展示。权限与范围的最终校验、固定引用和任务状态由后端负责。

## 平台与共享角色详情加载

平台“角色与授权”的角色详情默认打开权限标签。详情与当前授权并行请求；最新发布版本标识从当前授权的 `revision` 摘要读取。具备治理资格的平台自定义角色另行读取分配版本分布，首屏共三条请求；其他角色或无治理资格时首屏两条请求。详情首屏不调用版本历史分页，也不加载应用任务列表。

详情、权限、分布、历史和任务分别维护加载、错误及重试状态。主骨架只等待详情，慢或失败的分布请求不阻塞权限展示。历史与任务在首次激活标签时分页加载，默认每页20条；返回已加载标签保留页码与数据，不重复请求。发生相关变更后失效列表，只立即刷新当前激活且受影响的标签。

基本资料保存只刷新详情；版本元数据保存刷新当前授权摘要、分布并失效历史及任务；权限发布刷新详情和当前授权并失效历史及任务；应用成功刷新分布并失效任务。任务支持手动刷新，任务详情继续采用既有运行中轮询。

点击权限编辑时并行读取所选固定版本的完整详情与授权，保留来源版本、字段权限及乐观锁。切换角色或关闭抽屉后，迟到响应不得写入新上下文；同角色刷新保留应用向导状态。本加载策略属于 platform 插件的平台及共享角色抽屉，组织角色公共详情的加载策略保持既有实现。
