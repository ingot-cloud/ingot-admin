# 公共字段访问控制页面规则

## 能力来源

资源目录集中定义逻辑字段，后端将不同 DTO 的实际属性绑定到逻辑键。前端新增字段只配置资源能力，不自动产生业务表单、SQL 条件或访问授权。未接入字段允许保存，但未接入的能力不能发布有效授权。

字段可见性与操作能力分开消费：行级 `fieldAccess` 描述实际对象的可见性与编辑结论，全局 `fieldOperations[actionCode][fieldKey]` 描述当前查看者对精确操作的能力。目录上限和当前页面样本不能代替授权结果。字段排序权限已移除，既有业务排序继续使用。

## 查看与编辑

- HIDDEN 字段不展示标签、值或输入，后端安全响应不包含该属性。
- MASKED 字段只读展示后端返回的掩码。有编辑权限时输入从空草稿开始，不将掩码写回、不补取原值。
- FULL 字段正常显示完整值，编辑仍受行级 editable 和业务对象能力约束。

共享 `fieldTextDraft/fieldTextPatch` 按实际输入事件标记 dirty。未触碰字段不提交，明确清空业务允许的 nullable 字段提交 null。禁止以 `***` 等文本猜测状态，禁止以空草稿自动清空未修改的脱敏字段。隐藏或不可编辑字段不会进入 PATCH。

平台成员、组织成员和通讯录使用这些共享规则；成员创建与更新仍受各自精确操作能力和对象门禁约束，通讯录不因字段可见而获得管理编辑。只读时间字段按原场景载荷及可见性显示。

## 筛选和上下文刷新

筛选控件仅在对应精确 action 的 filterable 为 true 时显示。上下文缺失、加载失败或身份切换时，先关闭旧能力；上下文按身份、授权版本及场景刷新，并避免过期请求覆盖新结果。

禁止的受控条件由共享工具剔除，页面重置页码和查询键。后端在查询/count 前再次校验条件授权与整个有效查询范围的完整可见性；前端显示筛选条件不构成授权。

## 资源字段配置

“编辑资源”的字段能力以只读摘要列表展示，突出展示名与逻辑键，并分别展示支持的可见性、编辑/筛选、脱敏说明和后端接入状态。支持搜索；添加入口固定于字段区域标题处，列表滚动不影响添加入口。

新增和编辑通过独立字段弹窗完成。弹窗使用深拷贝草稿，取消无副作用；确认只更新资源本地草稿，最终由资源保存统一提交并携带 expectedVersion。已持久化字段键只读；本次新增或创建向导尚未持久化的字段键可修改。

接入状态同时用于摘要与弹窗，统一使用 InTag；状态说明区分已接入、未接入及清单读取失败。已声明支持的能力仍须后端绑定并获授权才能生效。后端接入标题、标签和说明垂直居中；表单标签与控件按统一列宽对齐。

## 脱敏规则交互

共享编辑器提供手机号、邮箱、全部遮盖、保留头尾、指定区间五种规则。每种规则均展示说明、可修改示例原文和即时效果预览。区间以用户可理解的自然编号输入，并映射后端参数；长度、短值及 Unicode 按公共规则处理。预览只使用示例，不请求业务原值。

已绑定非文本字段禁用 MASKED；选择脱敏时规则必填。不开放脚本或正则。规则配置作用于资源当前版本，不能绕过后端的字段权限和掩码处理。

## 角色和租户策略

平台角色字段步骤、授权预览及摘要分别展示可见性和操作能力，保留授予来源范围。角色发布不自动升级已有分配；需要采用新权限时由授权人员显式升级。

租户成员字段策略分别配置查看者/目标范围可见性与查看者级编辑/筛选规则。操作规则不混入目标范围，最终仍受业务对象更新边界和平台能力上限限制。

接口字段结构与 IAM/SDK 同批升级。接口副本保存在归档 change，本文只维护页面行为，不另建独立后端契约。
