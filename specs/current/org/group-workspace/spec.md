# 组织用户组工作区

`/org/iam/groups` 使用注册键 `org.iam.groups`。用户组列表载入后默认选中首条；切换组后加载对应有效成员页。创建和编辑使用分步向导，成员与部门来源分别配置，部门可指定包含下级。

右栏由服务端有效成员分页驱动。成员同时有直接和部门来源时只显示一行并列出来源。不可披露部门名称时显示部门范围。部门任职变化后刷新即可更新结果。移出操作只解除直接关系，来自部门的有效成员资格仍按部门规则计算。

左栏和用户组选择器使用 `view=SUMMARY`，按原分页读取摘要。工作区首次选中组后独立加载右栏有效成员页。查看详情、添加或移出成员时先取目标组的完整绑定与版本，再按编辑资格提交。
