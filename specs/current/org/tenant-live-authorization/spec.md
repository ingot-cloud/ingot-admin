# 组织即时授权与角色工作区

`/org/iam/authorization` 使用注册键 `org.iam.authorization`。角色工作区左侧搜索和分页角色，右侧独立分页成员、用户组；成员可查看直接分配与组继承来源。共享角色在组织侧只读，私有角色使用创建和编辑向导。权限及字段选择按应用展示当前配置。平台共享角色由平台向导维护，保存当前权限后关联组织后续请求即时求值。

角色分配使用角色身份。新建支持多个成员或组与多个角色的组合，预览后提交；编辑、撤销和查看来源按服务端能力开放。角色分配内提供候选式权限诊断，按权限选择成员、应用、操作和对象。授权管理员向导按角色和资源配置委派范围，受限管理员只使用自己的有效来源。

拥有者标记与操作资格由服务端返回，拥有者不是可分配角色。变更保存后主动刷新当前会话授权。页面可见时，已过期的权限状态可以触发核对；两端均不按 `expiresAt` 定时轮询。切换身份后旧响应不回填。平台自有角色仍使用 [固定版本与批量应用](../../base/role-version-application/spec.md)。
