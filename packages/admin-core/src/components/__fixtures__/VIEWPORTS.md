# 视觉验收基线

在 `pnpm dev:admin` 登录后，按以下视口检查 `layout.main`。本 change 不改业务页面，可用任意已有列表页观察框架与共享组件。

| 视口 | 检查 |
|------|------|
| 1440×900 | 顶栏 56px 白底；品牌 / 搜索靠右贴操作区 / 操作按钮；侧栏面板 236px、外层 244px；页面背景 `#f5f5f5`；面包屑关闭或仅一层时内容顶距 = 左右 `--in-page-gutter` |
| 1280×720 | 菜单视口独立滚动；底部「收起导航」高 44px、距底 8px；控制区上方有 1px 分隔线，线与按钮间隔 8px |
| 1280×500 | 长菜单滚动时底部控制坐标不变；无版权时长页面滑到底后内容底部有 `--in-page-gutter`，列表工作面仍贴底 |
| 1280×800 / 1200 内容宽 | 成员式工作区：左栏 260px、右栏表格 tools 整组直出 |
| 1000 / 920 / 900 / 800 | 左栏自动收起为 0px；批量操作整组进入 `…`，邀请/添加始终直出 |
| 1024×768 | 侧栏 52px 收缩态只留一级图标；无二级 popper |
| <1024px | 侧栏覆盖层始终 236px；文案「关闭导航」；Escape / 遮罩关闭不写回桌面偏好 |

键盘：顶栏图标按钮、侧栏折叠、页内 Tab 左右方向键、抽屉关闭顺序。

对比度：主文字 `#1f2329` 与白底、次级文字与弱背景。

暗色：设置抽屉中切换主题后，顶栏/侧栏/Token 同步，无浅色硬编码残留。
